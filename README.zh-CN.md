# Spiderlings

[English](README.md) | **简体中文**

test.77 将蛛丝与腿袋脱困改为原生 KD 参数，以普通无特质面板模拟校准。Cut 在工具或锋利环境可用时最有效；茧显著增加体力消耗并保留真实内层。新大围场保留 3×3 核心，最大 9×9 外框，原队不分流。玩家回收支持付费 Spinner 接力，保留首次命中、兼容项圈与八来源极难定位。坍缩预警五回合；符文按触发时减速延长预警。新特殊楼层从首个 Boss 后第 5 层起开放，猎场分散普通 NPC 猎物供蜘蛛巡楼。巢穴生成和武器数值保留，继续依据模拟判断。见[数值记录](docs/spiderlings-test77-balance.md)。

test.76 修复共享情报占用唯一施工者、阻止未投入队伍补员，以及 NPC 警觉绕过玩家识别的问题。只有远程情报时，未完成围场保留最后一名可用工人；实时追击仍需原生玩家识别。个人交战、回收职责和已投入场地的拥有者保持优先级。

test.75 在当前地图共享已识别的玩家情报：敌对且可行动的 Spinner、Jumper、WebCaster、Tunneler、NestEntrance 和 MageSpiderlings 可报告原生感知，所有敌对 Spinner 队伍使用相同的已知位置、方向和年龄。没有新接触时，报告在四个正时间世界回合后过期；隐蔽变位和零时间读档不续期。盟友情报与 NPC 目标分别处理。保留 test.74 的原队维护、更大合法围场与外到内付费施工，以及 Spinner 八格视距、六回合施压、真实近战回收、兼容项圈和挂绳失败反馈。

test.71 将新装巢穴设置默认修正为 4/1/2/1/1，保留已有保存值（包括零）。test.70 只修改了选择器 fallback，空设置初始化实际仍为 2/2/2/1/1；此前新装默认说明有误。

Spiderlings 是适用于 Kinkiest Dungeon 5.4.92 的 Mod，包含幼蛛遭遇、逐层蛛丝拘束、丝茧和可切换的粉色蛛丝外观。

有效 Spinner 回收来源现在会显示对应颜色的牵引丝线，并按可见格裁剪。经破口离场只记录资格，仍须再次被符合条件的 Spinner 命中且有兼容颈部装备；成功接线或装备受阻会给出明确反馈。

有效蚀盾咒印范围内，每个实际游戏回合增加一层印记、最多三层，并刷新既有的3/4/5回合到期时间。重叠范围或重复处理不会同回合叠多层；触发后仍在有效区域时，下一回合可补印。离开停止刷新；符文和坍缩行为不变。

## 下载与安装

1. 从[正式版 Release](https://github.com/duromumuyazu74-rgb/Spiderlings/releases/latest) 下载 [Spiderlings_0.92.38.zip](https://github.com/duromumuyazu74-rgb/Spiderlings/releases/download/v0.92.38/Spiderlings_0.92.38.zip)。
2. 在游戏 Mod 管理器中载入该 ZIP。
3. 同时只启用一个 Spiderlings 版本。

请使用 Release 附件中的安装包。GitHub 自动生成的 Source code 压缩包包含开发仓库，不能直接作为 Mod 载入。

当前测试包为 `0.92.36-test.77`，此前 test.64 的原生验收覆盖 KD 5.4.92 和官方 GitHub `5.5` 分支提交 `12a77c8b`，后者版本标记为 5.5.3。每次运行时交付现在都会 fetch 该分支并完成双版本原生验收。test.60 修复敌对 NPC 不破网、牵引忽略已打开缺口，以及读档时免费增加施工进度的问题。test.59 增加敌人持续缠丝与魔典四件原生拘束，修复 NPC 两种颜色的腿袋，并修复缠裹完成后重试捕获仍扣行动的问题。开局试玩 Perk 已移除，控制台仍可进入复用测试场地。test.58 接入两种颜色的七阶段 Spinner 缠腿原画，角色恢复操作后继续播完最后 500 毫秒动画并收起拖尾。test.57 限制法师符文只能由 Mage 施放，并将 Spinner 丝质牵引移出通用拘束选择池，保留正常法术及 Recovery 的精确 ID 装备。test.56 增加两件 Mage 稀有掉落：织缚魔典与缠丝法杖。千丝归茧基础消耗 4 魔力，施法后再过两回合向内收束；缠丝束先绑定首个命中的敌人，再施加减速。每次有效 Mage 战利品结算有 15% 概率掉落尚未持有的一件武器。本测试包保留 test.55 的修复：幼蛛小队改为 −2 点负面 Perk，编队为六只；Mage 巢穴增援在任意楼层按配置权重参与，腹部图案在转向和施法时保持贴合身体。本版包含此前修复。Mod 管理器的 major 5 提示兼容两条版本线，不代表所有 5.x 均已验证。公开 [itch.io 网页游戏](https://ada18980.itch.io/kinky-dungeon)和维护者已安装的 Windows 游戏此前均确认为 5.4.92。详见[已验证环境及覆盖范围](docs/COMPATIBILITY.md)。

Spinner 根据近期原生识别到的位置，比较附近合法通道与围场，优先更多可用内区空间；通道候选仍须截获真实入口到出口路线。新围场选择合法的 9×9、7×7、5×5 或 3×3 外框，付费施工从外圈向内圈推进，大场地保留 3×3 核心，存档层级顺序仍由内到外。尚未投入施工的计划可随新识别到的位置换址；原队继续维护已投入场地，使用不同待岗位置而不分流拥有者。六种合资格敌对 Spiderlings 的原生已识别视线或实际听觉，为所有敌对 Spinner 队伍提供同一份地图玩家快照。潜行识别和视线检查仍有效；失去感知后只保留不足四个正时间回合的历史位置。共享玩家情报不会替换正在进行的 NPC 交战。通道复用原生墙壁并保留原生门。工人先准备可见但不挡路的通口，猎物进入后再消耗行动逐格封口。附近闲置队伍按成员真实可达距离补员，在途成员仍需走到各自位置，只沿空闲路径前进并在占位前停下。准备完成时，工人按当前位置一次性重分守岗；封场后共享近期原生观测，实际靠近猎物，不再受待捕分区限制。根据近期实际感知的来向，可以付费先开新通路、再关其他口；连续 12 回合未见目标、当前也无法感知时，通道队伍结束诱敌。玩家打出的破口保留损伤与重建等待。旧单入口围场及存档继续兼容。详见[通道选址说明](docs/spinner-passage-algorithms.md)。

test.68 减轻逐格预警底色，以错开的细丝牵引代替蛛丝片平移，并增强结算爆发的受限亮核和外围线条；保留固定危险格、角色下方紫／粉地面线网和无数字倒计时。保留 test.66 的事件交付、读档去重、有界几何缓存及 Rune 施法重验证。玩法时序与平衡不变。

Mage 丝弹命中后尝试施加普通 Spiderlings 束缚，固定危险格上的蛛丝聚拢预警、地面咒印和命中爆发同步显示，不再绘制数字倒计时。Mage 法术采用独立束缚配置，本版尚未新增专属物品。

这个测试包同时包含五巢“幼蛛侵扰”和三巢“幼蛛猎场”。幼蛛猎场由普通幼蛛占领，使用其他楼层同样的幼蛛种类和属性。它们在这一层巡逻、搜索不同阵营的 NPC，包括友方、商人和任务角色；同阵营目标不会互相锁定，实际交战仍受原生视距和视线限制。`nocapture` 等原生不可捕获目标仍不会被缠走。独立开发的巢穴监狱不在此包内，使用自己的 `prison.alpha.N` 版本序列；游戏中一次只启用一个 Spiderlings 包。

test.42 按完整原生旅程将侵扰和猎场的默认权重校准为 50、1000。侵扰可搭配任意主派系，猎场仅搭配 Maidforce；两者互斥，不改写主派系。两套运行时各模拟 5,000 次普通旅程，两种标签均出现在约 5.35% 的合格节点上。权重可在 Mod 设置中修改，0 关闭对应修饰符。请在新开局前设置：KD 开局时生成整张旅程图，已有预告和地图不会重抽。已保存的自定义值及旧默认值 750 均保留，要采用新默认值需手动改为 1000。详见[参数说明](KinkyDungeon-Spiderlings/Spiderlings_0.9_Parameter_Guide.md#幼蛛猎场楼层)。

test.40 修复两个楼层共用死亡回调造成的冲突，女仆摧毁任一楼层目标巢时都会按规则额外放出 Tunneler；猎场最终人口裁剪保留预设守卫；在侧房读档时也会迁移缓存中的 test.32 三巢猎场。五巢侵扰存档保留身份与进度。

test.31 为三个原始侵扰任务巢各配四名守卫，三巢全部击破后才能下楼。Spinner 的围场类型按真实行动从最小 3×3 外围开始建造，并可逐圈扩展；移动幼蛛通过自有蛛网时加速。WebCaster 蛛丝可黏住敌对 NPC，相邻幼蛛随后可支付三次行动，非致命缠走合格目标。BlindZombie 可以被黏住，但不会被缠走。

测试分支沿用 `0.92.36` 正式基线，并已包含正式版 `0.92.38` 的兼容修复。它增加了实验性的 Spinner 捕获和 Mage Spiderlings。法师幼蛛的丝弹命中后造成伤害，并尝试施加一件合格的普通蛛丝束缚；它也会布置可见的符文陷阱。在 test.26 中，符文布置时显示发光蜘蛛图标；踩中后先警示 3×3 区域，一回合后对仍在范围内的目标施加蛛丝。新生成的普通地图达到第 5 层或有效安全等级 0 时，只要有合法空格且未超过幼蛛人口上限，就会有一只法师幼蛛。法师敌人的贴图已经换成专用素材。法师专用的手臂拘束已移除。Spiderlings 头套选项默认开启；关闭后即使没有选择原生 NoHood Perk 也不会穿戴自有头套，丝茧和满蛛丝开局仍可用。目前只有正式版发布 GitHub Release；测试包按[开发说明](docs/DEVELOPMENT.md)在本地构建。

test.28 为 Spinner 训练场边框和玩家牵引线加入 T_Swizzle 新交付的 Pink 图，校正边框四角方向，并将四种 WebCaster 弹体效果替换为 v2 Normal/Pink 成对素材。现有蛛丝颜色选项同时控制这些图。

test.29 让 Spinner 建成的蛛网格也按所选颜色显示，修复 Pink 模式下场地仍出现灰白蛛网的问题。

Test.38 将新生成的五巢幼蛛侵扰默认分为 2+2+1，少量地图为 2+3 或五巢一组。第 3 层三种分布的抽选概率为 80%／18%／2%；五巢一组每深入一层增加 1 个百分点，第 31 层起封顶 30%，相应减少 2+2+1。地形不足时尝试其他合法分组。巢穴附近的闲置移动幼蛛会选择不同的可达巡逻地点，减少 WebCaster、Jumper 和 Mage 堆积；旧地图保留巢位，也可使用巡逻机制。旧单入口围场与通道场地并存，保留已有建设进度。Test.39 将边界统一为 `SpiderlingsSpinnerTrap` 的边缘和拐角，移除独立地面陷阱及踩点减速；旧场地迁移时保留建造进度与耐久。此包还补回已提供的法师幼蛛新图及施法粒子、光晕。
