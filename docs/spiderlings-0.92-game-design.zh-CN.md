# Spiderlings 0.92 设计基线

`0.92` 是玩法设计基线，当前正式版为 `0.92.38`，当前开发版为 `0.92.36-test.36`。正式安装包从 [GitHub Release](https://github.com/duromumuyazu74-rgb/Spiderlings/releases/tag/v0.92.38) 下载，开发包由 `test` 分支 CI 提供；已验证游戏环境为 KD 5.4.92 和 KD 5.5.3。详细数值以 [参数说明](../KinkyDungeon-Spiderlings/Spiderlings_0.9_Parameter_Guide.md) 为当前参考；Spinner 测试玩法见[试玩说明](spiderlings-spinner-capture/PLAYTEST.zh-CN.md)，模型、加载和发行约束见 [维护说明](../KinkyDungeon-Spiderlings/MAINTENANCE.md)。

0.92.36 补齐丝茧玩家的安静驻守条件：在丝茧中停止反抗且没有待完成加固时，玩家不再阻止据点十五回合后留五只，任务巢穴采用同一判定；不额外等待二十五回合散开警戒。玩家恢复攻击、挣扎、施法、尝试移动或附近可反抗 NPC 出现时重新计时。旧侵扰地图直接生效。

0.92.35 修复蜘蛛主动寻敌和驻守撤退：闲逛幼蛛也会寻找可达女仆，自身感知允许双方在画面外启动战斗；驻守安静计时只被可感知、可反抗的敌人打断，helpless／被囚禁／眩晕／冻结／noAttack NPC 不再阻止十五回合后留五只，恢复反抗则归零。新增 NPC 蛛丝封口：蜘蛛成功施加的 Slime 束缚仍在且目标 helpless 时停止发声和求救，恢复反抗后恢复；记录随存档保留，无来源旧束缚不推断归属。该规则取代下文 0.92.34 中“任何活着敌人都打断安静”的历史条件。

单图幼蛛上限默认 25，可在 Mod 设置中修改，0 表示不限。统计当前地图四类存活幼蛛（包含友方），巢穴不占名额；自然生成、游荡及重生、固定小队、循环增援和死亡召唤共享额度。小队名额不足四只时整组跳过，超额存档和调低设置保留已有蜘蛛并暂停新增。

每巢累计 Tunneler 上限默认 3（0 禁止该巢召唤掘穴幼蛛），只计成功召唤，不因子代死亡或建巢返还；新巢额度独立。上限耗尽后，其他正权重种类照常参与循环增援；原有单巢存活上限和单图上限同时适用。计数随实体保存；已有设置保留，旧巢按仍可归属的 Tunneler 初始化，已移除历史无法补计。

## 敌人与地图

| 敌人         | 基础生命值 | 主要行为                                                                           |
| ------------ | ---------: | ---------------------------------------------------------------------------------- |
| Spinner      |          2 | 近战施加蛛丝，实际新增或有效加固后离场                                             |
| Jumper       |          1 | 两格普通攻击，独立蓄力跃击锁定目标格，两次完整玩家行动后结算                       |
| WebCaster    |          1 | 喷网直击和残留蛛网，允许贴身施法并在三格内退避；多只交叉命中补缠，走位偏好分散射角 |
| Tunneler     |          1 | 在自身附近严格召唤一个 NestEntrance，成功施法后离场                                |
| NestEntrance |         12 | 固定巢穴，周期增援；死亡额外生成 Spinner×2、Jumper×1、WebCaster×1                  |

普通地图同时使用原生自然生成与默认开启的固定四人小队。自然权重依次为 `12/12/8/4/2`；小队原子放置四种移动幼蛛各一只，不追溯补放。循环增援独立受每巢子代上限、概率和间隔约束：默认上限 6、间隔 2 回合、基础概率 15%，五格内每个其他敌对巢穴再加 10%；增援种类权重 `2/2/2/1`。巢穴在警觉且看见玩家、原生感知到敌对女仆，或近期受到敌对 NPC 攻击时启动增援；受击警戒持续配置间隔＋1 回合（默认 3），不额外立即召唤。女仆会攻击默认敌对的这五种实体，原生友好、停战、队伍和仆从覆盖仍生效。

0.92.22 起，原地图修饰符在楼层选择和旅程地图中显示专属蛛网边框图标，保留底层区域图案；0.92.36-test.32 曾将显示名改为 Spiderling Hunting Grounds／幼蛛猎场。test.34 起保留独立的 Spiderling Infestation／幼蛛侵扰，并给幼蛛猎场独立 ID 和图标。

0.92.18 起，女仆与五种敌对 Mod 实体优先选择视野内的彼此，玩家距离更近不会抢走目标；没有合格对手时恢复原版选敌。玩家近战攻击（含未命中）或攻击法术命中后，被攻击者优先选择可见玩家 10 回合，再次攻击刷新；其他单位不跟随转火。NPC 互殴、友方召唤物攻击与治疗不触发。这一优先级适用于所有相遇场景，仍尊重视距、视线、友方、停战、队伍和仆从状态。

自 0.92.33 起，处于 hunt／wander 闲逛状态的女仆会按距离寻找 **12 格内**的敌对幼蛛或巢穴，优先接近原生短程寻路可达、路径不超过 24 步的对象；路不通或搜索预算不足时尝试其他对象，均不可达则继续原版闲逛。寻找目标不增加视距；走近且通过原生视线检查后，女仆进入警觉并按原生攻击规则交战，双方在玩家画面外也可启动战斗。正在追击玩家、挑衅计时未结束、已有 NPC 战斗目标、守岗、押送或执行专用任务时不接管。该行为同样适用于更新后载入的旧地图。

“幼蛛猎场”从第 3 层起按权重 100 参加原生修饰符抽选，新选出的猎场节点使用女仆主势力，旧节点和已生成地图保留原配置，权重不是每层独立发生百分比。五巢“幼蛛侵扰”仍以独立 ID `SpiderlingsInfestation` 和权重 50 抽选，沿用原生人口；三巢猎场使用 `SpiderlingsHuntingGrounds`，并让幼蛛巡逻、捕猎遇到的其他 NPC；同阵营幼蛛不会互相锁定，最终缠裹遵守原生不可捕获限制。合格地图在随机人口生成前放置三个独立任务巢，任意两巢棋盘距离至少 9 格；每处初始有 2 只 Spinner、1 只 WebCaster，归属该巢的活跃守军最多 4 只。每巢周围三格的普通墙体与碎石可清理，保留受保护地形；巢位阻挡后仍保持地图连通，且每巢可从相邻格攻击。生成失败则撤销整批，保留普通人口。猎场保留原生随机人口预算，蜘蛛／女仆／装扮公司／护士的随机池倍率为 3／0.35／0.2／0.2；地图生成结束后，女仆系战斗巡逻单位最多保留 3 名，商店 NPC 与原生脚本生成角色保留，游荡生成的女仆系单位不留在该层。普通女仆主势力地图沿用 1／3／0.5／1 的权重和游荡生成。监狱与守卫势力、囚犯、任务 NPC 和场景物件保留原版规则；固定小队、普通新巢和死亡爆怪继续使用各自规则。

0.92.31 起，女仆主势力层的初始随机人口不因原生中立额度耗尽而被要求敌对玩家，避免预设 NPC 先占满额度后清空女仆和装扮公司候选。保留其余筛选及原生总人口预算；预设遭遇、游荡搜索增援和其他主势力层的敌意条件保持原规则。

三个初始巢穴使用任务标记，其 ID、已摧毁 ID 和完成状态随地图保存。成功摧毁任意目标均计数，不限击毁者；后来召唤的巢穴不计入。未完成时禁止下楼和其他正向推进出口，包括直接或强制调用；上楼与同层侧房可用。完成存档记录的全部目标后开放原生奖励房和下层流程。旧五巢地图仍按存档中的五个目标计数和显示，重访不重生任务巢穴。

## 玩家与 NPC 攻击结算

0.92.27 起，玩家与 NPC 共用“轻微伤害＋绑定”：普通有效命中基础 0.05 tickle，跃击 0.10，喷网直击 0.05，轨迹 0.01，不因未推进追加伤害。对玩家成功推进蛛丝才消耗近战幼蛛。

对敌对 NPC，普通近战、跃击、喷网直击和轨迹同时分别提供基础 1.5、3、3、0.5 束缚。保留原生抗性、护盾、Slime 材料和挣脱，不生成实体装备；实际增加束缚才消耗近战或跃击幼蛛。蛛丝轻触、有归属的地面陷阱以及闭合蛛网围场可给仍有护盾的敌对 NPC 施加短时原生 `ShieldDrain`；围场内每回合刷新，强度比当前原生护盾回复高 2，破盾后才按原生规则绑定。蛛网破口会停止持续压盾。伤害与束缚分别受 tickle 与 glue 抗性影响；自有伤害增幅限制为原生倍率调整后输入的两倍，防止固定弱点奖励压过基础轻伤。轨迹按来源和目标每回合最多接触结算一次；对 NPC 无交叉喷网奖励。NPC 跃击锁定身份与原格，移开可躲避。目标是暂时制服；原生高阶 NPC 门槛仍然较高。

## 蛛丝进阶与操作

不同 WebCaster 在两玩家回合内直击可额外补一件合格内层蛛丝，全体每玩家回合最多成功追加一次。双方须存活、敌对、警觉、六格内且射线无遮挡；控制或失去射线中断配合。同只连射和残留蛛网不触发追加；追加不能结茧、修复 Cocoon 或额外叠 slow。站位只调整原生风筝移动的合法方向偏好，生命值、射速和移动消耗不变。

| 阶段   | 实体数量与部位                                                            | 有效逃脱行动                     |
| ------ | ------------------------------------------------------------------------- | -------------------------------- |
| Lv1    | 10：Arm、左右 Mitten、Belly、Legs、Ankles、Foot、Blindfold、Stuffing、Gag | 1 次                             |
| Lv2    | 5：Arm、Belly、Legs、Ankles、Foot                                         | 2 次                             |
| Lv3    | 8：五身体部位、Blindfold、Gag、Hood                                       | 2 次                             |
| Cocoon | 1：独立 ItemDevices 丝茧                                                  | Cut 40 次；Remove/Struggle 50 次 |

内层实体持续装备，各部位独立晋级，每次命中重新从未满部位的下一层按原权重抽选；同回合可以连续跨级，不要求全身先补齐同一级。Lv3 Hood 需要 Lv3 Blindfold 与 Lv3 Gag。原生 NoHood Perk 或 Spiderlings 的头套选项关闭时，不自动添加自有 Hood；结茧门槛改为其余七件 Lv3，满蛛丝开局也跳过 Hood，已有自有 Hood 会在下个游戏回合解除。允许 Hood 时仍需八件 Lv3。达到对应门槛（不要求 Lv1／Lv2 齐全）、命中前 slow 已达五层时，后续允许的直接命中才结茧。带来源的残留蛛网可推进 Lv1–Lv3，每回合最多一次，不能结茧。手动装备绕过敌方阶段前置。外部护甲和普通拘束在原生允许无覆盖添加且没有 blocker 时可共存，Cocoon 同样适用；外部实例、锁与进度保留，原生拒绝时不强制施加。

丝茧是最高级操作门禁，穿着期间全部 Lv1/Lv2/Lv3 不能操作，丝茧本身仍可操作。脱茧后恢复各部位外层优先的解除顺序。被阻挡输入不消耗回合、耐力或工具，不累计逃脱进度。最终 Cut 销毁，Remove/Struggle 回收到松散背包；Lv1–Lv3 的行动方法可混合。

当前脱困消息区分有效推进与真正解除，Cut、Struggle、Remove 分别描写割断、扯松和剥离蛛丝；丝茧使用独立过程与完成文案。无效尝试沿用原有阻挡提示，次数、扣费与最终物品去向不变。

普通丝茧允许缓慢移动。最近十二回合内有效逃脱与攻击意图合计三次触发待加固状态，WebCaster 主动优先瞄准视野内玩家，实际喷网 direct 命中添加外围网，固定至脱茧。未命中近战和攻击法术按行动计一次，治疗、buff 与等待不计；待加固 WebCaster 保持警戒并遵守原生施法限制。每次允许的 direct 最多修复总进度 10%。外围网是同一件丝茧的状态与图层，不是额外拘束。

结茧后敌对蜘蛛持续警戒，不再随机忽略已绑紧的玩家。挣扎、攻击、施法或试图移动都会重置计时，被外围网挡住的移动也算。只有连续 25 回合无主动行动，蜘蛛才停止攻击并逐步退至四格外，留出脱身机会；恢复行动即重新追击。散开时取消尚未完成的跃击。回合按游戏时间计算，包括行动的后续延迟回合。

## 外观与交付

Lv1 Legs/Ankles 在站立裙层下；Lv2/Lv3 在裙层上，以透明画稿覆盖并保留裙子。Lv1 无 displacement，Lv2/Lv3 共用五部位导出图。Legs 为 `Skirts/2000`、原点 `(110,1657)`；Ankles 为 `Skirts/2000`、原点 `(383,2085)`。

Lv3 覆盖对应内层显示和位移，实体仍保留。Hood 遮住头部和兽耳；Lv3 Legs 与丝茧遮住尾巴。丝茧本体只包到颈口下缘，手动单独装备不会补头罩。

正式文件以 manifest 的显式清单为准，共 93 项。当前测试版在此基础上增加四张 Spinner 腿袋 PNG、四张粉色敌人 PNG 和三个 Spinner 脚本，共 104 项。原色与粉色图集在启动时预载。

本版本未实现 Nest Depth 专属侧房、牵引捕获、多格 Boss 或通用阶段控制器。Spinner 测试场地的专用阶段逻辑不改变普通地图。当前范围以本文、参数说明、试玩说明和 manifest 为准。

### NPC 协作与任务巢逃生

三个独立任务巢分别清理自身周围三格的普通墙体与碎石，保留交互／任务格并重建导航；旧地图不重新开挖。原始据点 12 格内、没有巢穴父 ID 的野生移动蜘蛛共享安静计时；参与蜘蛛、归属守军和任务巢附近 12 格无可感知且可反抗的敌对目标连续 15 回合后，保留最近 5 只无父 ID 野生蜘蛛，其他非击杀撤离。归属守军、普通新巢子代、友方、队伍、被俘和远处蜘蛛不参与撤离；巢穴保持，少于 5 只不补生，计时随地图保存。

喷网幼蛛拥有原生胶抗性。对敌对 NPC，两只不同且仍满足存活、警觉、敌对、六格物理视线和可行动条件的喷网幼蛛在两回合内成功直击绑定，会额外尝试基础 Slime 绑定 2，无额外 HP 伤害；每目标成功后冷却四回合，冷却随 NPC 保存，读档清配对窗口。玩家协作与两种轨迹限频各自保留。

Maidforce 的致命伤害击毁原始任务巢之一时，原生死亡回调先尝试额外一只 Tunneler，再执行原有死亡幼蛛。此死亡额度独立于每巢累计／存活额度，仍遵守单图 25 默认上限及合法落点；普通巢及非女仆击杀不变，新造巢不成为任务巢，也不继承任务巢守军上限。全部任务巢被女仆击毁仍会正常解锁前进。

据点复审后的边界：清墙保留原本不可达区域的围墙（含斜向通路）；安静时间同时检查回合开始／结束与群体内部敌意。依据 SpiderlingsHuntingGrounds.js；验证见 `.scratch/spiderlings-clearing-review-20260913/`。
