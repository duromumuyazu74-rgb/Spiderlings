# Spiderlings 0.92.27

幼蛛对玩家与敌对 NPC 都采用“轻微伤害＋绑定”，共用攻击伤害配置。

| 攻击 | 基础 tickle 伤害 | NPC 基础束缚 |
|---|---:|---:|
| 普通近战 | 0.05 | 1.5 |
| 跃击 | 0.10 | 3 |
| 喷网直击 | 0.05 | 3 |
| 喷网轨迹 | 0.01 | 0.5 |

玩家继续获得合格的蛛丝装备，NPC 增加原生 Slime 束缚；原生抗性与护盾可能抵消其中一种效果。普通近战与跃击成功推进绑定才消耗幼蛛，仅造成伤害时保留。

修复 NPC 弱点固定加伤将微量伤害放大的问题，自有轻触伤害增幅最多为原生倍率调整后输入的两倍。喷网轨迹限频同时约束伤害与绑定，交叉绑定奖励不增加伤害；喷网伤害保留实际施法者归因。

验证：228 项自动测试通过；KD 5.4.92 和 5.5 的原生玩家命中、NPC 近战、喷网、延迟跃击、抗性、护盾、25 回合混战及存档往返检查通过。
