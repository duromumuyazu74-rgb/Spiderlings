# 多层场地最低常驻

状态：已采纳。日期：2026-10-09。[Issue #148](https://github.com/duromumuyazu74-rgb/Spiderlings/issues/148)。

捕获场地的最低常驻随有效层数累计。L 层需要 L*(L+1)/2 名 Spinner，一层为 1、二层为 3、三层为 6、四层为 10。已退役或地形失效的层不计。场地人口许可仍为 floor(n/4)，同时受设置中的最大场地数约束，常驻门槛不替代许可或设置。

FieldCommand 先满足所有现有场地的最低常驻分配，再处理可选施工、待备和借调。出借不能让供给场地低于自己的最低常驻。常驻调配更改 home，临时借调保留 home；任一成员只有一个当前指挥。正在捕获、牵引或执行已批准冲刺的成员保留原行动。

常驻表示长期归属和本场地指挥配额。成员执行本场地的捕获、引诱或回收任务时仍占该配额，实际到场、在途、任务外出及失能分别统计，不能将分配承诺报告成已经到场。新常驻经原生付费移动抵达，本场地既有任务不因补位而反复切成集合任务。

在途永久常驻被批准执行本场地接触任务时，结束集合行程并保留 home 和当前指挥；不能套用临时借调的返程规则清空指挥。已有猎物归属的场地也不能因运输中的目标坐标改变而按未施工工程重选位置，地形失效仍正常检查。

短缺保留为可见缺口，成员死亡或失能后重新计算。最低分配缺口存在时暂停新增独立工程，不刷出额外 Spinner，不自动删除旧场地，也不缩小已有结构。多场地存档逐 composite 接管，不能只采用第一座场地或依赖全局 graph.kind。

原生场景 field-residency 验证两座三层场地、最低分配优先、付费到场、存读档及死亡补位；field-command 和 field-reinforcement 继续验证临时借调与直接改派。人口许可使用真实人口独立验证。
