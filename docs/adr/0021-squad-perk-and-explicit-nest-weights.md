# 小队改为负面 Perk，巢穴增援直接使用配置权重

- 状态：已采纳
- 日期：2026-09-27
- 替代：[0009](0009-guaranteed-spiderling-squad.md)

按维护者要求，将默认开启的小队设置改为原生 Enemies 类负面 Perk `SpiderlingsSquad`。界面显示 −2 点，原生内部 cost 为 −1，选择后增加两个可用点数。每张合格新普通地图增加两只 Spinner，以及 Tunneler、WebCaster、Jumper、Mage 各一只。六只按完整单位生成，保留人口上限、10/4 安全距离、失败回滚和地图一次性状态；旧地图不补放，旧全局设置不自动选择 Perk。

六只优先使用 3×2 或 2×3 矩形，无法放置时在锚点切比雪夫半径三内寻找连通六格。每个锚点只生成一个广度优先候选，避免把原四格组合穷举扩大成六格后的组合开销。空间不足时整组跳过。

维护者明确巢穴权重只影响循环增援，自然生成、保底生成、固定小队、手动编辑器生成和死亡爆怪不受其控制。权重 0 禁用该种增援，全零时不使用默认种类兜底。Mage 的巢穴增援按配置权重参与，移除自然生成的第五层／安全等级门槛，避免低层的 Tunneler=1、Mage=1 被暗中变成只出 Tunneler。自然和保底 Mage 保留原门槛。

Tunneler 成功造巢后仍由原生逻辑退场，新巢仍有独立的增援额度；这次没有修改建巢机制或添加全图巢穴上限。关闭巢穴 Tunneler 权重可以停止该来源的后续 Tunneler，既有和手动放置的 Tunneler 不被删除。
