# 场地猎物归属与显式行动

状态：已采纳。日期：2026-10-08。[Issue #148](https://github.com/duromumuyazu74-rgb/Spiderlings/issues/148)。

成功场地捕获建立可保存的猎物归属，独立于暂时的 Capture/Recovery 来源。其他 NPC 牵走该猎物时，场地分配少量可感知目标的幼蛛主动攻击竞争者；不静默抢写原生牵引，也不让全体工人停止工作追逐玩家。后续专属监狱承接这一归属，本次不引入监狱玩法。

场地为成员决定工作、回收接触、护送、守卫和拦截职责。原生系统负责行动费用、失能、视线、命中与实际位移；它的闲逛或忽略受缚玩家策略不能否决场地已批准的动作。未分配行动的场地成员守候，不恢复独立选敌。跨物种拦截任务补充 ADR-0024 中非 Spinner 只接受区域目标的限制，原有施法、冲刺和活动控制来源仍受保护。

只持有腿袋不建立新捕获归属。旧存档可从与当前腿袋 ID 匹配的、已有场地归属的 RecoveryDeparture 或活动 Recovery 恢复记录。移除该腿袋且不再处于 Capture 时释放归属。运输以实际到达最近可达场地中心为完成，中心和牵引通道留给猎物，援助来源在外围停靠。

2026-10-08 用户澄清：穿腿套且实际从整个场地内部越界到外部，才建立玩家回收资格。偏离中心、跨越内层但仍在外层内、仅有项圈或腿套均不触发。回到中心后消耗记录，再次回收须再次越界。旧版缺少越界凭据的临时回收及待回收记录失效，真实装备进度保留。猎物归属与攻击竞争牵引者独立于回收请求。

未建立来源的接触者按可见性与可达性选择，实际已连接来源仍受保护；远程拦截按法术射程和射线选择可达站位，不能要求远程单位先占据近战相邻格。
