# ADR 0002：保留 Spiderlings 拘束存档兼容

- 状态：已替代（见 ADR 0003）
- 日期：2026-07-27

## 背景

Spiderlings 的新拘束族将淘汰 `WebArms`、`WebLegs2`、`WebGag` 等碎片化旧 ID，改为五个完整模块及其重度对应物。已有存档可能在玩家装备栏或其他持久状态中引用这些旧 ID。

## 决策

支持已有 Spiderlings 存档。重构后的加载／迁移逻辑必须将玩家拥有的每个旧拘束实例（已装备和背包）映射到最接近的新完整模块或重度模块；不处理地图、敌人或其他模组物品。在迁移期保留旧 ID 的兼容识别，不直接删除其定义。

## 后果

- 新拘束使用 Spiderlings-owned 新 ID，避免旧名称继续定义新设计。
- 迁移是幂等的：同一存档重复加载不会反复替换或叠加物品。
- 未能一对一映射的旧拘束保留为可安全移除的 legacy 项，并记录诊断，而非静默丢失。
- 测试必须覆盖空装备、已装备和背包内的旧模块、完整旧套装、旧全茧以及混合其他 KD 拘束的存档。
