# 猎物进入核心后保留付费施工职责

- 状态：已采纳，Spiderlings 0.92.36-test.83
- 日期：2026-10-02

玩家侧审查在 test.82 复现了持续停工。普通无专长角色抢先进入尚未完工的共同核心后，全体 Spinner 转入近战。三个随机种子各等待 512 原生回合，付费施工停在四次，九件下身束缚饱和且意志归零，场地仍未封闭，玩家仍可六次移动走出六格。玩家随后要求根据报告改进玩法与怪物行为，授权采用施工与施压分工。

保留已分配工人的真实移动与付费施工。可信猎物位于未完工核心时，本体施工先于该工人的普通近战分支，包括相邻后的原生防御分支。诱敌者维持原生追击与近战。若另有可行动成员能到达该本体任务的合法未占用工位，诱敌者不占用本体任务，已有本体任务移交给工人；其封口任务仍保留。没有替代工人或情报过期时沿用既有分配规则。任务转移不重置施工信用或拓扑进度。

Capture、Recovery、巢穴防御仍优先。施工支付、工位占用、路径、失能、击杀和边界损伤仍由现有规则判定。保留原队、外到内施工、大场地偏好与小地图合法回退。进入核心本身不施加束缚，捕获仍需真实近战命中和已闭合边界。没有新增全知感知、免费施工、额外束缚或详细战术播报。

对照结果和最终包复测见[资深 KD 玩家模拟反馈的改进记录](../spiderlings-gameplay-improvements-2026-10-02.zh-CN.md)。它比较连续等待、真实工位阻挡、打晕和击杀工人的结果，保留主动反制带来的停工。单纯让非相邻工人继续施工的初步方案仍在 160 回合内无法闭合，因此未采用。

## test.95 维修分工细化（2026-10-05）

玩家报告猎物留在受损场内时，Spinner 全部围绕猎物而不维修。Capture 原先连视野内非参与者的维修也抢占。保留合法维修 assignment，使其优先于新招募与绕场待命；已有玩家 Capture 来源全部占用同队成员时，只为真实可达的维修调出一员，并始终保留至少一名有效来源，不重置编织、挣脱或物品进度。线状场地维修同样先于该工人的普通近战。Recovery、巢穴防御及未调出的实际 Capture 来源仍优先；单一有效来源、不可达工位或失能不能凭空产生维修。NPC Capture 仅保留非参与者的维修职责，已有来源不拆除。
