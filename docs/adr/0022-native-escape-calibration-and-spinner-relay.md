# 原生脱困校准与 Spinner 回收接力

- 状态：已采纳，Spiderlings 0.92.36-test.77
- 日期：2026-10-01
- 部分取代：test.89 的玩家回收改用原生 tether 与无上限移动回合，删除独立拆线操作；见[变更记录](../spiderlings-test89-native-recovery.zh-CN.md)。以下八来源决策保留为历史依据。

玩家要求撤销蛛丝和腿袋的固定有效动作数，将 Lv1 约一次、Lv2 约两次、Lv3 更强、完整腿袋更强、茧明显最强作为普通角色面板的模拟目标。KD 原生拥有进度、成功结果、工具和环境亲和、特质、锁与物品去向；Mod 只配置原生 chance、speed、minimum speed 和茧的原生体力费用倍率。次数不再成为运行时门槛，也不保证任意面板都相同。

Cut 在原生允许使用工具或锋利环境时最有效。茧不绕过切割可达性；其强度差距由低速度、高体力支出、移动限制和真实内层共同形成。原生 delayed struggle 每个正时间 tick 至少增加 0.04，单纯降低 chance 无法兑现此前 40/50 次门槛。保留三次／十二回合的茧加固频率检测，该记录只触发后续 WebCaster 直接命中加固，不能完成脱困。旧动作计数一次性转换为低于完成阈值的原生 struggleProgress，不改变锁、链接或物品身份。

回收最多八个来源的情况保留为极难遭遇，没有撤离宽限期。首次挂绳仍须真实命中、兼容项圈和原生装备允许。已离场队伍内的其他合格 Spinner 可在三格、原生 LOS 的接力链上支付后续行动接线；同次接线不拖拽。整个链必须连到实际接触玩家的根，远端环不能自行支撑。NPC 捕获、回收或包裹职责优先。主动拆除的来源需要新的真实命中，不能在拆线的敌方阶段立即通过接力恢复。外部 leash 和原生牵引所有权保持。

场地保留已投入队伍；新大围场外框最大 9×9，内圈保留 3×3 核心，外到内付费施工。小地图使用合法回退，旧图不移动。玩家提示保留动作反馈、挂绳失败与实际法术预警，不新增详细围捕预测。

特殊楼层的新普通节点从首个 Boss 后第 5 层开放，已访问楼层保留。猎场随机人口保留其他 NPC，初始普通猎物按合法可达格分散，闲置野生蜘蛛巡楼；已投入 Spinner 不参与分流。巢穴生成与武器数值在本次保留，依据双版本模拟继续判断。数值与证据见[模拟记录](../spiderlings-test77-balance.md)。
