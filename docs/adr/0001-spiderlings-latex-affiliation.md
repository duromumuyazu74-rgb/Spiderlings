# ADR 0001：蛛丝拘束挂靠 Latex

- 状态：已采纳
- 日期：2026-07-27

## 背景

Spiderlings 的蛛丝拘束需要与 KD 5.5 的神殿净化、声望及既有物品分类协同。可选方案包括沿用已有的 `Latex` 归属，或新增一个 Spiderlings 专属教派／好感度体系。

## 决策

所有重新设计的 Spiderlings 蛛丝拘束继续使用 `Latex` 归属，并附加 Spiderlings 自有分类标签（例如 `SpiderlingsSilk`）。不新增教派、神祇声望、地图神殿或专属 UI。

## 后果

- 可复用 KD 现有的 Latex 净化与声望兼容行为。
- 避免新增派系初始化、地图生成、翻译、UI 和旧存档迁移的兼容风险。
- `SpiderlingsSilk` 标签可用于模组内部掉落、敌人施加和成套逻辑，但不代表新的全局声望体系。
- 若未来玩法确实需要独立社会关系或神殿循环，再以新的 ADR 评估该扩展。
