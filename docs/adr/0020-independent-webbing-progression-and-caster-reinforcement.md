# 按部位晋级与 WebCaster 丝茧固定

- 状态：已采纳，Spiderlings 0.92.29
- 日期：2026-09-13

按用户本次修订，取消 [ADR 0006](0006-lv1-and-lv2-physically-coexist.md) 的全身阶段门槛，保留真实内层并存和部位内顺序。五个身体部位各自 Lv1 → Lv2 → Lv3；眼罩 Lv1 → Lv3；口部 Stuffing → Lv1 Gag → Lv3 Gag。Hood 仍需要 Lv3 Blindfold 与 Lv3 Gag。左右手套各自只有 Lv1。

每次命中读取最新装备链，每个未满部位提供至多一件下一层候选，与空部位一起按原来源权重随机。满级部位退出候选，原生添加不兼容的部位不会挡住其他部位；无全身等级锁，也无跨级等待回合。同次普通命中仍只添加一件，WebCaster 交叉奖励按原上限另行选择。Cocoon 仍要求全部 23 件内层及命中前五层 slow，兼容性规则沿用 ADR 0019。

丝茧最近 12 回合内的有效脱困与攻击意图合计 3 次后保存待加固状态。近战未命中也计数，攻击法术按行动计一次；治疗、buff、等待和无效脱困输入不计。WebCaster 优先转向视野内玩家并持续使用原生喷网，仅其直接命中施加外围网。距离、视线、状态、施法冷却仍由 KD 决定；没有合格施法者时保留请求。Spinner/Jumper 可以修补进度，不能施加固定。

原生验证覆盖 KD 5.4.92 与 5.5：连续 23 次同回合施加保留全部内层；一次 Remove 与两次未命中近战触发请求，WebCaster 的原生 AI 转火、施法、命中后固定。记录和脚本见 `.scratch/spiderlings-cocoon-diagnosis-20260913/`。
