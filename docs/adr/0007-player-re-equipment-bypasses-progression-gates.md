# 玩家重复装备绕过 Spiderlings 进度门槛

- 状态：已采纳
- 日期：2026-08-01

Spiderlings 的 Lv1、Lv2 与 Cocoon 都是可库存、可由玩家主动装备的拘束。一旦物品已经合法进入玩家背包，玩家可以直接装备它，不再检查 Spiderlings 敌方进度门槛。

因此，玩家可以在 Lv1 未齐时装备持有的 Lv2，也可以在没有任何 Lv1、Lv2 或 WebSpray 五层减速时直接装备持有的 Cocoon。9 件 Lv1、7 件 Lv2、预先存在的五层减速以及“第五层之后再命中一次”等条件，只决定敌方共享拘束流程何时能够施加 Cocoon，不构成背包装备成本。

玩家手动装备 Cocoon 成功后，立即清空已有的全部 WebSpray 减速层数及计时器，与敌方施加成功后的状态一致；这些层数不是装备成本，即使原本为零也允许装备。若 KD 因槽位冲突等原因拒绝装备，则不得清除层数或计时器。

该决定允许玩家主动制造不完整或非标准装备状态，所以实现不得从 Cocoon 推断 Lv1/Lv2 已齐，也不得从 Lv2 推断对应 Lv1 存在。所有门槛、加固和逃脱逻辑都必须检查当前真实装备链。普通掉落、商店、宝箱、制作与 KD 随机拘束池仍不提供这些物品；可重复装备不改变首次正常获取边界。

玩家可以任意选择装备顺序，但最终 Spiderlings 自有动态链接链必须规范化。每次玩家装备一件 Spiderlings 物品后，模组原子重排受影响 Group 内的 Spiderlings 自有物品：普通同部位固定为 `Lv1 → Lv2`，手套固定为 Left Lv1→Left Lv2→Right Lv1→Right Lv2，口部固定为 Lv1 Stuffing→Lv1 Gag，均由内到外。重排只改变链接，不删除重建物品，必须完整保留身份、紧度、逃脱进度及其他实例状态；非 Spiderlings 物品不属于这次规范化的排序成员。

自由重复装备只绕过 Spiderlings 自己的进度门槛，不绕过 KD 对同 Group 外部拘束的原生装备与链接检查。已有原版或第三方物品时，Spiderlings 不得删除、替换、重排、强行链接或绕过它；KD 拒绝装备时，新物品原样留在背包且不运行规范化。KD 接受装备时，也只规范化 Spiderlings 自有子集，外部物品及其实例状态必须保持不变。

装备链内的原子规范化保留现有实例状态，但真正完成解除并回收到背包时结束旧装备实例。最后一次有效行动为 Struggle 或 Remove 时，背包得到零逃脱进度的新松散物品；再次装备后，Lv1/Lv2 从零进度开始，Cocoon 恢复为完整的 `40/50/50` 基准，不继承此前的破损或加固修复状态。
