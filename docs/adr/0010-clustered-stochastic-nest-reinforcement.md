# NestEntrance 使用聚集度驱动的可配置随机增援

NestEntrance 按玩家配置的 `2–20` 回合间隔进行增援检查，间隔默认两回合；基础成功率为 15%，并由五格内其他存活、敌对 NestEntrance 各增加 10%，最高 100%，成功后依次在半径 2.5、5.0、7.5 内寻找位置。玩家继续配置 Spinner、Jumper、WebCaster、Tunneler 的 `0–10` 选择权重，默认 `2/2/2/1`，并配置每个巢穴的存活增援上限；上限默认 6，允许任意非负整数。相比旧的确定性召唤，这让巢穴聚集本身成为额外战术压力，同时保留玩家对增援组成、节奏和数量的控制；概率公式、邻近判定和搜索半径保持固定，以免配置组合掩盖聚集机制。
