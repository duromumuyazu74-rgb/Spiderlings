# 普通战斗地图采用保底幼蛛小队

- 状态：已采纳
- 日期：2026-08-11

Spiderlings 将原先“自然刷怪加无蜘蛛时随机补一只”的普通地图保证，改为默认开启、可由 `Spiderling squad` 设置关闭的固定小队：每张新生成、符合 KD 敌人/生成规则且存在合法完整位置的非 Boss 普通战斗地图，原子生成 Jumper、WebCaster、Tunneler、Spinner 各一只。小队是额外的最低遭遇保证，不替代或限制自然蜘蛛和 NestEntrance；旧单只 fallback 退出。

选择确定性小队而不是继续依赖自然聚团，是为了让四种角色稳定共同出现。代价是从第一层起增加固定遭遇压力，并让每张合格地图都有 Tunneler 建巢的潜力；默认开启但可整体关闭的设置承担这项玩家侧取舍。为避免保证破坏地图，小队仅在完整紧凑阵型满足 `10/4` 切比雪夫安全包络时生成，失败整队跳过，不覆盖实体、不降级、不追溯旧地图，也不在重返地图时补员。

## 2026-09-25 修订

保底小队增加第二只 Spinner，现为 Jumper、WebCaster、Tunneler 各一只与 Spinner 两只。两只 Spinner 在同一紧凑落点簇中，可自行满足自动布场编组的最低人数；布场仍须在后续回合按行动预算完成。小队需要五个合法格与五个人口名额：优先采用 `2×2` 方块加一个相邻格，找不到时才尝试其他连通紧凑五格；任一前置条件不足则整队跳过。此修订取代上方的四只编制和四格落点，其余一次性生成和 `10/4` 安全包络保持适用。
