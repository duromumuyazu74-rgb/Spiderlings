# 施工优先与低价值场地退役

状态：目标设计已采纳，尚未实现。日期：2026-10-07。

唯一可行动施工者在有合法施工时请求支援并继续完成场地，不因贴身目标或受到攻击切换为普通自卫。原生失能、占位、成本和实际捕获、拉回来源保护仍有效。这避免仅靠持续贴近就令工程永久停工，保留通过实际阻塞或击败施工者进行反制的机会。

选址先要求对目标当前位置或合理预计路线形成有效拦截，再在有效候选中优先合法多层大场地。只有结合目标覆盖、大小、已完成进度与剩余施工成本后，替代方案明显更优，才允许放弃低价值小场地。角色移动本身不清空工程。

明确退役会结束场地指挥、撤回工人、释放捕获场地名额；已支付结构保留为残网，但不再自动封锁、捕获、维修或作为拉回目的地。正在承担真实捕获或拉回的场地暂不退役，共享结构不得影响仍在运行的场地。这修订 ADR-0024 的已投入工程默认持续保留运行策略，解决低价值旧工程长期占满部署名额的问题。

持续停工时先更换合法工位或可行动施工者，再请求支援；仍不能推进时报告实际阻塞原因并重新评价工程，短暂受阻不直接退役。无人使用且不被在用场地共用的退役残网逐渐自然消散，并保留正常破坏途径，避免反复更换工程令地图结构持续累积。
