# 蛛网推进保留护甲并服从原生合法链接

2026-09-13 修订：本决定的“仅护甲可兼容”限制及仅为护甲保留 unlink 实例的范围，由 [ADR 0019](0019-webbing-preserves-native-compatible-external-restraints.md) 扩展至原生允许无覆盖添加的普通拘束和混合链；其他完整阶段与原生合法性约束延续。

2026-09-08，用户确认合作者反馈 D1：普通护甲占槽时保留护甲，仅在 KD 原生允许无损链接时施加蛛网，继续要求十件真实 Lv1 全齐后才能进入五件 Lv2。原先把全部外部同组物品一律排除，会使原生可兼容的护甲也永久挡住完整套装；选择合法叠加可恢复这部分推进，同时保留护甲身份、效果和既定完整内层玩法。

同组存在非护甲外部拘束、原生 blocker、链接拒绝或不支持姿势时仍拒绝该候选；不自动卸甲、替换外部物品、强制链接或忽略缺失部位。正常命中最多新增一件，失败不重掷；护甲继续留在装备链，无背包或地面转移，其身份、相对顺序及实例状态不得被 Spiderlings 自有链规范化改写。

解除 Spiderlings 外层后仍保留护甲身份及进度。实机发现 KD 原生 unlink 会重建刚露出的护甲根，丢失原 ID 与逃脱进度，因此仅对直接覆盖护甲的 Spiderlings 层补充实例保留适配，继续执行原生解除事件及蛛网物品去向。该适配不改变其他装备的解除规则。

此决定补充 [ADR 0006](0006-lv1-and-lv2-physically-coexist.md) 的物理并存原则和 [ADR 0007](0007-player-re-equipment-bypasses-progression-gates.md) 的外部物品保护边界，沿用当前十件 Lv1、五件 Lv2 目录。Cocoon 仍要求十五件真实内层、命中前五层 WebSpray slow 和后续允许的 direct 来源；玩家手动装备仅绕过敌方进度门槛。Lv1/Lv2 的现行衣物可见规则保持，护甲叠加资格不等于授权改变整体遮挡策略。

2026-09-08 后续修订：用户确认将八件 Lv3 接入现有敌方进阶，形成十件 Lv1 → 五件 Lv2 → 八件 Lv3 → Cocoon。Cocoon 的物理内层门槛相应增至二十三件，保留命中前五层 slow 与后续 direct 条件；Lv3 Hood 要求先有 Lv3 Blindfold 和 Gag。此修订让已交付的 Lv3 能在正常战斗中出现，结茧前增加八次成功施加；护甲保留、每次一件和玩家手动装备例外继续适用。
