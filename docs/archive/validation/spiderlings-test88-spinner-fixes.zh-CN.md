# Test.88：Spinner 现场问题修复

基于 test.87（`a2d17cb`），对应 Issue #113。调查使用玩家提供的截图，以及从仍在运行的 Windows 游戏磁盘存档复制出的第 886 回合现场；没有接管或热更新桌面进程。复制存档在独立 KD 5.4.92 原生运行环境加载。该次落盘时玩家已无截图中的拘束，腿袋逃脱和再次命中的过程通过隔离原生场景重建。

## 原因与改动

- 现场留下 62 个场地记录，多组施工队反复放弃未开工选址。新增观察会改变接近方向，而旧代码允许过早重选。现在给观察后的接近保留 12 个协调回合；工人继续缩短到工作格的距离时，再保留 8 回合。已付费场地继续由原队维护。
- 已发现猎物时，场外工人容易放下围场施工。现在保留非诱敌者的主体施工职责，诱敌者继续负责施压；回收、捕获及保卫受攻击巢穴的优先级保持。实际行动仍支付原生移动和施工费用。
- 废弃场地仍可能先于重叠的新场地被查询命中。废弃场地不再参与包含判定；重叠有效场地优先选择已满足捕获几何条件的场地。
- 边界的实际耐久来自其物理蛛网，原生悬浮提示却读取固定敌人定义的最大 HP，造成 `30 / 20`。现在逐格同步 `Enemy.maxhp` 和实体最大 HP，并设置原生 `modified` 标记，防止刷新和读档还原为默认值；受伤不降低最大值。
- Spinner 非腿部拘束权重原为零。改为保留腿部的 `2/1/1` 偏好，其余部位权重为 `0.25`。四种现有攻击者均能完成所有兼容内层部位；成茧仍需要既有 WebSpray 条件。Jumper 成功后的消耗、Tunneler 造巢职责不变。
- 自有回收丝绳原来只能通过项圈准入。现在也接受蛛丝腿袋，移除最后一个锚点时仅移除自有丝绳。读档时迁移旧自有丝绳保存的项圈专用事件，保留其他事件与物品进度。挂绳失败不再吞掉普通束缚机会；拖回共同核心后结束临时拖拽职责，保留真实物品并恢复后续束缚。外部 leash 的锁、逃脱进度、动态链接及原生所有权不变。

## 武器描述

按本次追加要求，两件武器的物品详情直接说明特殊能力。织缚魔典写明六格内丝圈、两次后续行动后收束、中心更强、最多三层加织及其法力／行动／延迟代价，以及主副手束缚加成；缠丝法杖写明六格射程、首个敌对目标的束缚减速及墙壁阻挡。两者都说明有效命中和自有蛛丝首次完整成茧的有限资源返还，具体消耗与冷却继续放在技能提示。

英文及七语共 16 条详情完成独立语义复核，保留既有技能名称与“可返还”的条件含义。短描述仍保留材质与外观，避免与左栏武器数值重叠；原生背包页面检查换行和边界。

## 性能观察

固定第 886 回合存档、相同随机种子，在独立 Chrome 原生游戏中比较 test.87 和 test.88 性能候选（ZIP SHA-256 前缀 `eddc19f299a6`）。该候选包含最终版相同的绘制缓存与资格筛选改动，早于逐格 HP 和旧丝绳读档修正。边界绘制取 12 批、每批 100 帧，丢弃前两批，以剩余批次中位数比较；现场有 4 个实体边界，62 个场地记录。时间包含绘制入口调用，不等同于整帧 GPU 时间。

| 指标                     | Test.87 | Test.88 性能候选 |
| ------------------------ | ------: | ---------------: |
| 100 帧边界调用中位数     |  5.4 ms |           0.7 ms |
| 后续 30 个等待回合中位数 | 19.4 ms |          20.5 ms |
| 第 30 回合实体数         |      47 |               55 |

边界样式按不可变 topology 对象和格子缓存，废弃记录退出绘制及部分目标查询；施工复用地图格索引。猎场选敌先排除同阵营、巢穴和场景对象，再执行较贵的战斗资格检查。不会缓存阵营、状态、视线或动态占格。

边界调用开销已下降，但修复改变了后续施工、出生与战斗轨迹，整回合数据不能证明整体卡顿已经消失，也不能作为 Windows 桌面 FPS 结论。原始现场副本、日志和性能样本保存在本地 `.scratch/live-save/`，不提交玩家存档。

## 验证

新增原生 `spinner-regressions` 场景检查四种来源的完整内层进阶、Jumper 消耗、腿袋准入与上身进阶、读档及锚点移除，以及 2／4／8 只工人在移动猎物面前付费施工和边界最大 HP。`player-recovery` 改用无项圈腿袋验证自主追击、真实命中、拖回及回到核心后解除临时职责；原有多来源及外部 leash 测试保留。

同一新增场景在原版 test.87 上实际失败：连续 100 次 Spinner 命中仍只有腿、踝、足三个系列共九件内层拘束；修复版四种攻击来源均以 23 次进阶完成全部内层。最终双版本和交付检查结果见 [COMPATIBILITY.md](../../COMPATIBILITY.md)。
