# Test.131 协作施工与猎场约定

关联 [Issue #140](https://github.com/duromumuyazu74-rgb/Spiderlings/issues/140)。此次交付包括图鉴威胁说明、场地施工调度与猎场生成约束。

## 当前行为

织网和喷网幼蛛单独的直接威胁较低，数量增加时，通过牵制、贴近、补网和喷丝减速协作形成更高威胁。图鉴说明这种区别。掘穴幼蛛不与来客交战，但留下的新巢口可能带来其他幼蛛。英文和七种翻译的 24 条改文经过独立审校，保留原生见闻段落和署名。没有修改敌人伤害或生命值。

场地已接敌时，规划优先跟随这个角色的当前坐标，随后才比较其他角色的可达距离。围场工作按照实际路径距离分配给合适成员，避免远处低 ID 单位拿走近处空闲成员可以完成的关键任务。付费结构、最大场地数、借调归属和原生攻击感知规则保留。

猎场只在第5层起、主势力为 Maidforce 的合法普通楼层出现，任务固定摧毁三个原始标记巢穴。未摧毁前不能正常下楼。大型初始场地按空间优先布置，其数量不能取消已经可成立的三巢穴任务。空白格的空元数据记录不算受保护格；有内容的锁、任务等元数据仍保留。原生整图重试先释放上次尝试自己的布局保留标记。

无法成立的生成拒绝整个猎场类型，使用原生楼层人口和逃脱条件。旧取消状态的人口计划会清理，已存在单位及合法活跃任务进度保留，已进入的地图不会被自动重建或改换主势力。

## 复现与回归

旧 test.130 的正常猎场种子测试允许布局取消，30 个样本中有 17 个没有三巢穴任务。这是验收缺口。新的原生断言要求每个合法 Maidforce 样本都成功初始化三个标记目标。墓地第5层、地下墓穴第7层和图书馆第12层各十个固定种子在候选包的 5.4.92 测试中均已通过。

地下墓穴第7层种子3原先因为缺少两个大型围场而转为钥匙任务。允许优先使用可成立的大场地后，同一生成入口得到三个目标巢穴。墓地第5层种子1还暴露了空元数据和原生整图重试遗留保留区的问题。公共回归分别覆盖小地图任务成立、空记录、受保护格、原生布点保留和实际任务进度。

两个调度公共回归在旧实现中失败：最后一项施工由远处低 ID 单位抢先取得；已经接敌的场地仍用更近的无关 NPC 规划。修正后通过。相同受控六人场景的 20 个回合，候选版记录 34 次施工，旧版为 22 次；这是该场景的观察值，不是所有地图的时间保证。新增原生入场场景包含守卫 AI，观察多名实际付费施工者和原生近战接触，并检查读档不增加施工进度。

最新第15栏的副本位于第7层，原生主势力是 Bountyhunter，却曾被错误选择猎场，随后取消布局并使用钥匙任务。此次不会把这个已生成楼层强改成 Maidforce 或凭空重建三巢穴任务，而是清理旧的错误猎场人口计划，并保证后续合法新猎场的三巢穴约定。原始游戏存储未写入。
