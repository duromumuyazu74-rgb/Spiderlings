# 大场地选址与双向牵引修复

版本 `0.92.36-test.114`，对应 [Issue #122](https://github.com/duromumuyazu74-rgb/Spiderlings/issues/122)。

## 行为变化

新建围合场地不再找到附近的小空地就停止搜索，也不再只检查角色接近路线旁的远处位置。总控比较连通地图中的合法候选，先选最大的内部面积，再按角色位置、距离和现有工程决定同等规模的选址。地形、保护对象、其他场地的占地和可达性仍参与验证。空间足够时选择 9×9 外边界的三圈场地，继续从外圈向内付费施工。合法通道的路线拦截优先级保留；已付费施工的存档场地保留，不因更新强行拆建。

领牵 Spinner 朝场地中心前进，协助 Spinner 让出中心和领牵者的接近路线。人数较多时可在第二圈停靠，避免把最内圈占满。让位和前进使用原生敌人移动积分。领牵者到达中心后收紧原生牵引，由原生碰撞处理移动角色并让牵引者让位；到达后立即结束本次拉回。腿套的后续追捕资格仍保留。

角色反向移动使用正常的原生移动行动。移动成功且丝线实际超出长度时，依次牵动直连 Spinner 和它们的中继连接。位移仍由原生牵引处理；不增加额外回合，也不覆盖蜘蛛已有的其他牵引。丝线尚未拉紧、移动失败和零时间操作不会触发反向牵动。多来源移动债务、真实项圈载体和存档字段保留。提示只描述实际发生的牵动方向。

巢穴设置左栏包含五项种类权重及其简短说明，右栏包含两个上限的标题与输入框及增援间隔。原设置值保留，默认楼层权重仍是 200／2000。七种语言同步了分组标题与双向牵引消息。

## 验证范围

公开回归覆盖近处小空地与远处大房间的比较、小地图回退、中心让位、原生付费反向移动、失败移动及其他牵引的保留。扩圈工作统计包含多个继续施工的工程，按每个工程一次下一圈检查计算上限。

原生场景覆盖大房间优先、规划不赠送施工、多来源移动债务与重载、持续反向移动后的拉回、协助者占据单格中心、堵住斜向出口、反向牵动，以及设置的两列分组与 HTML 输入框。借调场景保留真实忙碌拒绝原因，并由总控招募可用预备成员再派遣，不要求被现有职责占用的成员无条件出借。施工场景按原场地归属核对团队保留，并检查每个并行工程的外圈优先顺序；临时借调不等于改变原归属。完工判据要求一个完整的三圈场地，而非不同工程凑出三个完工圈。

NPC 捕获维修场景提供三名供援成员，允许受威胁的供援场地保留两名本地成员，仍要求真实借调者付费修复并保护两名原捕获来源。感知场景保留实际原生识别门槛，将初次识别者放在稳定的感知距离内；压力追踪场景只提供一个合法围场，核对未识别的新位置不会替代已识别的历史位置。

本机 KD 保存栏的存档仅复制到隔离测试环境。旧版复现角色停在场地外；修复包在正常付费回合后把角色带回原场地中心。完整浏览器截图另核对了中文设置的输入框、标签位置和保存值。原存档和本机游戏文件未修改。

最终安装包、双版本完整验收与交付检查记录见[兼容性记录](../../COMPATIBILITY.md)。这些测试覆盖指定存档和受控原生场景，不代表完整游玩或其他 Mod 的兼容性。
