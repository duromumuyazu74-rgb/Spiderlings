失败消息不再保证割口加深、网隙扩大或丝层剥开。原生 KD 在无法获得逃脱进度的前几次尝试中也可能返回 `Fail`，所以英文及七种本地化均描述尝试动作和蛛丝反应；只有真正解除时使用完成措辞。西语 Lv3 缚腿描述中残留的连接词也已修正。

等级名称保持“蛛丝 / 缠织蛛丝 / 密织蛛丝”，对应 `Silken / Woven Silken / Dense Silken`。武器保持“织缚魔典 / 缠丝法杖”，调用 ID 仍为 `SpiderlingTome / SpiderlingStaff`。

武器自身的蛛丝足以使敌人完全无力，才显示完整茧；外来束缚不能替代这个条件。挂绳失败提示仍明确说明兼容项圈及装备阻挡，脱困消息区分尝试与真正解除。
