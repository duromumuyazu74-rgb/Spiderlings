# Test.99 Spinner 建场与 NPC 退场

Spinner 的最后一名围场施工者不再因为亲自看见 NPC 猎物而全部转去追击。亲自接触玩家仍保留原有追击优先级。多人队伍仍由接触成员追击，其余人员施工；独立或只剩一名可用施工者时保留未完成场地的付费工作。贴身且仍能行动的敌人允许原生防御，既有腿袋拉回和巢穴防御仍优先。失能猎物不会让施工者站在旁边停工。

移除了覆盖在 NPC 上的黏住、无力反抗和蛛丝易伤文字，实际丝缚和茧的美术保持。设计方针只放在维护文档中。

原先完全黏住后的四倍受伤倍率会把血量很快压进原生击倒条件。KD 对完全受缚的倒地 NPC 使用 0.001 HP，界面可能显示为零。这轮取消额外伤害，HP、护盾和击倒继续由原生处理。

合格敌对 NPC 连续六个游戏回合保持完全黏住，或由足够自有蛛丝造成原生无力行动后，允许非致命离开地图。达到阈值的瞬间不清血、不移除。挣脱、解绑或恢复行动会重置窗口。进度随实体保存，现实时间、绘图、零时间读档和同一原生 tick 的重复通知不推进。原生取消移除时保留目标，下个正时间回合重试；成功退场归还携带物品，不触发死亡掉落、任务击杀或永久收编。

这是给持续受束目标腾出场地的可恢复窗口，不改变 Mage 本来具有的直接杀伤。其他 Mod 的原生取消仍有效。
