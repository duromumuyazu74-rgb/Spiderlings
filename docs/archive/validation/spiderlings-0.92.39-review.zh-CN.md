# 0.92.39 正式发布审查

日期：2026-10-09。[Issue #150](https://github.com/duromumuyazu74-rgb/Spiderlings/issues/150)。比较基准为上次正式 Release `v0.92.38`，审查输入为 `45086d8` 的 test.151 及本次 test.152 修正。正式版下一版本为 0.92.39，发布与下载验收仍需绑定最终 main 提交及其 CI 安装包。

## 已修复的发现

Mage 的丝球、符文、咒印和坠牢仍各自判断旧的 Maidforce 范围，遗漏原生属于 Adventurer 的两种女仆骑士，以及场地批准攻击的中立牵引竞争者。原生 test.151 探针对普通女仆记录 4 点伤害及 6 点基础绑定输入，对两种骑士却只记录玩家用的 0.5 点伤害路径。符文触发和咒印应用的定向单元回归也先复现失败。

敌对规则现在提供 `Rivalry.isMaid` 只读查询，三个法术模块共同使用。猎场猎物和 FieldCustody 当前批准的拦截对象分别保留自己的准入来源。法术仍检查原生敌意并保留护盾、抗性、友方、玩家及失效拦截的原路径。三组新回归、既有友方法师与来源保存回归均通过；新增 `mage-rivalry` 原生场景验证真实女仆骑士的飞弹行进和自有蛛丝，以及法师实际向中立牵引者施法并绑定。

与 main 的完整比较还发现六个旧策划演示维护文件未通过检查。它们依赖仓库未提供的 scratch 画师演示源，手册仍将已经完成的捕获系统写成待实现。移除失效构建器、验证脚本和源文件，保留生成的历史 HTML、当时验证记录与 Git 历史入口；当前职责、参数及验收由现行文档维护。没有放宽语法、格式或运行时检查。
