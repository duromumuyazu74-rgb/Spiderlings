# test.94 猎场人口、组队捕获与大型场地

本次按用户确认保留击杀 NPC 的能力，优先协同束缚和控制。完整自有蛛丝的四倍易伤、原生护盾、反击和死亡流程不改。Spinner 的“埋伏”继续指布置场地，保留 test.93 已修复的立即接敌行为。Mage 命中引爆仍清空印记层数。

## 人口与行为

猎场蜘蛛上限始终取全局单图设置加 20。默认 25 对应 45，只在其他地图上将全局 0 解释为不限；猎场为 0 + 20 = 20。读入旧猎场立即采用新上限，不补刷初始人口。超额已有蜘蛛保留，暂停新增直到空出名额。

新图保留三个任务巢及每巢完整六人队。剩余额度先安排完整巡逻队，再补足移动蜘蛛。默认目标人口为 45 只蜘蛛、5 名分散的精英女仆、1 名服装公司成员和 1 名护士。已有原生守卫计入对应配额，只补不足部分；必要场景出生可超过猎物配额。人口统计包含对玩家中立的可移动战斗 NPC，避免女仆和服装公司漏计后占据过多名额。

同一巢队或巡逻队优先配合已有猎物，避免相邻成员各自选择不同 NPC。共享消息只来自成员的实际原生观察。本人看不到目标时只能调查旧坐标，记录不足四回合有效，不读取失联猎物的新位置。有效巢穴警报优先于追踪其他猎物，已分配的付费施工继续保留。

## 大型场地

新猎场需要两座合法的 9×9 大型外围捕获场地。每座由对应巢队原有两只 Spinner 驻守，出生在内核，不另消耗额外四个名额。外圈预制保持通行口，内圈和封口继续消耗真实行动。小型可选场地不能替代这两座场地；旧图不重挖或重新分配驻守位置。

原生验收发现，原有布局只确认场地内部空间，没有保证外环封闭后地图仍可通行。这会使已经出生在第二座场地的 Spinner 无法初始化其外围。生成器需要在规划时验证并保留外侧通路，沿用场地运行时的连通性检查。

选址还需要登记到原生预设房间的保护区域，避免后续房间覆盖场地。规划器对原生可走地板的判定与场地运行时保持一致。

地图重试原先会替换嵌套的出生点数组，但原生生成器仍保存旧数组引用，导致失败地图的出生记录混入新地图。现在原位恢复这些列表，回归测试同时检查引用和内容。旁路只开辟合法普通墙，不要求额外的 11×11 整圈空地。
