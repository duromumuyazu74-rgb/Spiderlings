# Triage labels

Spiderlings 使用同名 GitHub labels；其他产品的本地 ticket 使用同名 `Status:`。

| Canonical role | GitHub label / local status |
| --- | --- |
| `needs-triage` | `needs-triage` |
| `needs-info` | `needs-info` |
| `ready-for-agent` | `ready-for-agent` |
| `ready-for-human` | `ready-for-human` |
| `wontfix` | `wontfix` |

GitHub Issue 使用 `bug` 或 `enhancement` 表示类别，状态标签每次保留一个。完成状态使用 GitHub closed；本地历史 `done` 记录保持原样。

Wayfinder 类型标签为 `wayfinder:map`、`wayfinder:research`、`wayfinder:prototype`、`wayfinder:grilling` 和 `wayfinder:task`。它们与 triage 状态分别表示任务类型和可执行状态。
