# Triage labels

Spiderlings uses these GitHub labels. Other products in the original KD workspace use the same names in their local `Status:` field.

| Canonical role | GitHub label / local status |
| --- | --- |
| `needs-triage` | `needs-triage` |
| `needs-info` | `needs-info` |
| `ready-for-agent` | `ready-for-agent` |
| `ready-for-human` | `ready-for-human` |
| `wontfix` | `wontfix` |

An Issue uses `bug` or `enhancement` for its category and one triage state label at a time. Completed Issues use GitHub's closed state. Preserve historical local `done` records.

Wayfinder type labels are `wayfinder:map`, `wayfinder:research`, `wayfinder:prototype`, `wayfinder:grilling` and `wayfinder:task`. They describe ticket type separately from triage state.
