# 楼层修饰符权重校准

test.42 将幼蛛猎场默认权重由 750 改为 1000，侵扰保持 50，保留原生修饰符的权重保持 800。目标是让两种标签在完整普通旅程中的总体出现率接近。猎场仍只接受 Maidforce 主派系，侵扰接受任何已确定的主派系。

## 原生 Monte Carlo

每个运行时、每套参数使用同一组 5,000 个种子生成完整旅程。调用原生 KDInitJourneyMap(0)，保留真实区域后继权重、派系池、候选缓存、出口和侧房抽选。普通旅程进度为 grv/cat/jng/tmp/bel，每检查点 4 层，最大层数 21。统计所有分支中 type=basic、y≥3、无特殊 RoomType、非 Hell 的节点，每套共 325,000 个。

区间使用 5,000 个独立整局均值的标准误乘 1.96。同一局中的节点共享候选缓存，不能按节点独立计算区间。默认 1000 下两个版本的差异区间均包含零。所有候选参数下，猎场与非 Maidforce 主派系搭配数均为零。

5.5 参考运行时的界面版本字符串为 5.5.0，源码对应本地参考快照；此前四区域抽样记录称其为 5.5.3，这不足以证明特定 5.5.3 安装版已验证。本轮按实际运行时标识报告，未推广到所有 5.5 补丁。

## 复现范围

在加载本版 Mod、以默认普通旅程新开局的隔离测试游戏中，分别设置侵扰 50，猎场 750、1000、1100。每组循环 run=0…4999，按以下过程固定随机源后调用 KDInitJourneyMap(0)：

```js
let seed = (0x971700 + Math.imul(run + 1, 0x9e3779b9)) >>> 0;
Math.random = () => {
  seed = (Math.imul(seed, 1664525) + 1013904223) >>> 0;
  return seed / 4294967296;
};
KDsetSeed("test41-review-full-balance-" + run);
KDMapModRefreshList = [];
KDInitJourneyMap(0);
```

逐局统计上述节点的 MapMod 与 Faction，完成后恢复原 Math.random。此操作重建测试局的旅程图，不用于正在游玩的存档。记录的是地图预告标签，没有模拟玩家选路、地形放置失败或实际遭遇数。

本地回归测试 spiderlings-hunting-grounds.test.js 另用原生旅程、区域、派系和 Boss/Hell 函数生成 4,000 局；出口和侧房函数使用固定返回值，作为快速概率回归。测试要求两类计数之比在 0.9–1.1，旧默认 750 得到 12,144 / 13,955 而失败，新默认 1000 得到 14,025 / 13,843 而通过。最终校准依据为上表完整运行时结果。

## 配置生效

KD 在开局时预生成整张旅程图。请先保存权重再开新局；旧旅程包含未访问节点在内均保留。升级不会覆盖已保存的权重，旧值 750 需要手动改成 1000。两项配置均接受非负整数，0 禁用对应标签，非法输入使用本版默认值。
