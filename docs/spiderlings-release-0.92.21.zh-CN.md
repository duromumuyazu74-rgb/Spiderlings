# Spiderlings 0.92.34

距离上一次重制已经过去了一段时间。这期间，**T_Swizzle 协助制作了全新的手工绘制美术素材，替换了初版重制使用的 AI 素材。**

现在有了**三个层次的蛛丝风格拘束，以及最终的 Cocoon 丝茧形态**，均提供原色与粉色两种配色，可以自由切换。

**Jumper 跃击幼蛛有了新的跃击攻击方式，Web Caster 喷网幼蛛也学会了团队协作。**

从第 3 层起，将有机会随机出现**蜘蛛 infestation floor（幼蛛侵扰楼层）**。**女仆势力会主动寻找蜘蛛，清理它们的巢穴。**

提供了多种 **Mod 选项**，可以按照自己的喜好调整难度。

新增**“丝茧初醒”开局**，让你穿着全套蛛丝拘束与丝茧开始冒险。

已在本地 **KD 5.4.92** 版本测试，目前也支持 **5.5 GitHub 开发版**，但不保证后续更新仍然兼容。从旧 AI 素材版升级时，请使用新存档。

感谢美术作者 **T_Swizzle**，也感谢原 Mod 作者 **anthropocentricity**！

如果游玩过程中遇到任何 bug，或有任何建议，**欢迎留言，也可以附上截图反馈！**
