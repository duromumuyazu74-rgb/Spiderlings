# 缚丝织庭：织巢主母 Boss 设计案

状态：设计规格与试玩实现。当前试玩使用放大的 Spinner、实际 `3×3` 占位和 prison 内入口；数值仍需试玩校准。更新日期：2026-10-25。

试玩分支基于 prison V6 的 `04fd788`。使用方法与实际实现范围见[试玩说明](BOSS-DEMO.zh-CN.md)，验证和包身份见[兼容记录](COMPATIBILITY.md)。[Issue #165](https://github.com/duromumuyazu74-rgb/Spiderlings/issues/165) 跟踪正式美术、数值和后续交付。下文的候选值仍是调试方向，不等于最终平衡参数。

[打开 HTML 展示页](spiderlings-boss-design.html)

房间提案名为「缚丝织庭 / Silkbound Court」，Boss 暂名「织巢主母 / Nestweaver Matriarch」。战斗分为一阶段、四巢再生转场和正式二阶段。阶段内以世界回合安排固定机制；主母本体技能正常释放，三种瞬发召唤技能另行循环，只在召唤组内共享冷却，两者可同时发生。具体距离、回合数、生命和伤害参数仍待调试。

## 1. 房间、入场与胜负

- Boss 位于监牢的独立附属房间。入口在 V6 prison 主巢东侧 `(64,31)`，避开原有六处施工预留范围；玩家入场出现在地图中心，主母从场地边缘登场。胜利后南侧通道返回原来的 prison 地图。
- 主母是参照原生龙体量设计的多格大型单位，具有实际的多格占位。具体格数与外形在原型中确定，地图入口、通路和最小围场按完整占位留出移动空间。原型需核对多格移动与碰撞、点击和攻击判定、近战接触以及技能预告；身前终击的牵引落点位于主母占位外的可达邻格。
- 同时出现八只 Spinner，从场地最外围开始施工，逐圈向内建立围场。
- 主母入场立刻开始本体攻击与瞬发召唤轮转，与 Spinner 施工同时进行，不等待首圈闭合或教学轮结束。立刻开始仍保留各招式自身的正常预告与读条。
- 房间正常出口在战斗中关闭，最终击败二阶段 Boss 后才开放。一阶段生命归零不解锁出口、不结算胜利或奖励。
- 战败押送属于通往监牢的独立流程，不算打通房间。监牢脱困后返回房外，玩家可整理和恢复；再次入场从一阶段重新开始，主母、敌人、四巢与围场恢复开场状态。玩家自身的拘束、密度与资源保留实际状态。
- 时间按 KD 世界回合推进；菜单停留与思考不推进。耗时行动可能推进多个世界回合，预告需要显示实际剩余时间。

入口直接出现在 V6 prison 地图中。原生侧室连接保存来源监牢，胜利返回入口附近，战败押送返回同一监牢的囚禁区，两者都不推进旅程。监牢已有居民、宝箱和破坏状态保留。当前战斗中的存读档继续原战斗；只有战败离场后的再次入场才重置遭遇。试玩不提供专属剧情或奖励。

多格主母只有一份生命与敌人身份。点击任一占位格都选中同一目标；近战按占位边缘计算接触，同一次范围攻击覆盖多个占位格也只命中一次。移动逐步检查完整占位，不能穿墙、挤过窄口或覆盖玩家与其他单位。首轮原型采用固定朝向的方形占位，视觉转身不旋转碰撞形状；具体边长由第 7 节原型确定。

最终胜利保留在本房间的进度中，重进或读档不重生主母、不重复发奖。玩家已穿戴的拘束、层数、密度和资源保留，战斗结束只解除本场临时控制。原生战败若先于魔织丝茧超时发生，按普通战败条件接入监牢，并使用同一房外返回点；不凭战败事件补发魔织丝茧。

## 2. 八只 Spinner 与逐圈围场

八只 Spinner 分布在场地最边缘的八个方向，分别领取不同的施工任务。围场从半径 13 格逐格缩至 5 格，共九圈，相邻圈紧贴、不留空行，最终中央内部为 9×9 格。完成最内圈后，施工者开始攻击和捕获玩家。

施工必须显示结点、连接和闭合过程，不能直接生成完整内圈。第一版候选流程为「完成当前环 → 向内推进施工位置 → 建立下一环 → 最小环闭合 → 切换捕获职责」。最小环是有实际可移动面积的战斗区域，不缩成零面积。

最小环闭合前，八只施工者只施工，不攻击玩家；闭合后接入普通攻击与 Spinner 捕获玩法。沿用捕获链路时，需要核对真实命中、合法来源与围场资格；不能把「建成最小环」直接等同于穿上魔织丝茧。

玩家可以破坏结点，也可以提前击杀施工者。存活施工者先修复当前环，再向内推进；击杀全部八只可阻止继续收圈，不补员、不赋予无敌。玩家因此可以在攻击主母与处理施工者之间分配行动。修补耗时与施工者减少后的施工速度仍待校准；主母从入场起便与施工同时进攻。

向内施工时保留已经建成的外圈。存活施工者优先修补当前施工环，再继续向内推进。玩家在圈外也会继续封口和缩圈；施工速度与破网耗时仍需实战校准。转场保留已有蛛网，不自动拆网或开口；玩家自行破坏结点，沿途穿过保留的各层蛛网，为通往四角巢穴的路线打开缺口，不要求先拆掉整圈。玩家可以先击杀施工者再开路。

## 3. 主母的三种召唤技能

以下三项是主母的瞬发召唤技能，只在这三项之间共享一个冷却，按固定顺序循环。第一版候选顺序为「四角喷网 → 双侧跃袭 → 四隅坠牢 → 重复」，不额外随机抽取。召唤即时触发，不占用本体技能的行动或施法机会，不打断正在进行的本体读条，不延后本体冷却；本体技能也不阻塞已到时的召唤。可以在主母释放其他技能的同时召来一组支援。

主母另有独立的本体招式组，包括下述拘束攻击、触发魔织丝茧的「魔织结茧」与维持密度的「织纹共鸣」。设计时间轴需分别列出「本体技能」和「瞬发召唤」两条并行序列，让主母招式与支援共同封锁走位。共享冷却只限制下一次召唤，不能扩成主母全部技能的公共冷却；被召出的幼蛛仍按各自的动作、预告和法术规则结算。

| 技能     | 数量与站位                                                   | 行为与结束                                                                       |
| -------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------- |
| 四角喷网 | 四只 WebCaster，出现在距玩家一定距离的左上、右上、左下、右下 | 每只朝玩家释放一次喷网，随后退场；共四次喷网                                     |
| 双侧跃袭 | 六只 Jumper，分成左右两组，每组三只，出现在玩家两侧          | 保留普通攻击与跃击预告，一次攻击结算后无掉落退场，落空、被挡或被躲开也退场       |
| 四隅坠牢 | 四只 Mage Spiderlings，出现在距玩家一定距离的四个对角位置    | 每只在玩家附近不同的偏移中心施放一次「千丝坠牢」，四个范围都覆盖玩家，结算后退场 |

「千丝坠牢」是敌方法师技能 `SpiderlingsMageCollapse`，与玩家魔典的「千丝归茧」区分。当前法师实现具有预告与延迟结算；Boss 召唤的 Mage 需保留到结算结束，因为现有结算会检查施法者仍然存在。

四个法阵的中心彼此错开，且都不与玩家位置重合；布置时每个法阵的实际覆盖范围都包含玩家，形成共同覆盖区。施法者的四角出生位置与法阵中心分别确定。偏移距离按千丝坠牢的实际覆盖格校准，不能只用圆形半径估计，也不能把四个法阵画成同中心重叠。伤害、拘束、密度和多法阵重叠均沿用千丝坠牢的正常结算逻辑，不增加 Boss 专用叠加或封顶规则。具体偏移与预告长度仍待调试。

召唤位置围绕本次玩家位置安排，按下述固定坐标关系锁定。正式落点要经过地形与占用检查，四角或两侧关系不能因临墙而变成贴身无预告包围。展示页只画布局示意，不代表最终格子距离、法术范围或命中结果。

召唤成功时开始组内共享冷却，冷却长度待定。上一组尚未结束不阻止下一组入场；主母处于禁止施法的控制状态时暂停触发，恢复后只释放当前应到的一组，不补发积压组。瞬发不取消幼蛛进场后自身的攻击预告或 Mage 法术读条。WebCaster 与 Mage 的一次性退场不触发普通死亡召唤、掉落或再次攻击；已经发出的喷网仍需保留合法来源，不能因移除施法者而丢失命中或重复结算。

### 落点、数量与人口

每次实际召唤前锁定玩家位置。四角以地图坐标的四个象限为准，Jumper 左右组以地图东西方向为准，不随玩家朝向翻转。出生之后，喷网、跃袭和千丝坠牢分别按自身预告锁定攻击目标；预告已经显示的攻击格不会随玩家移动重算。四重千丝坠牢共用一次目标位置快照，四个偏移中心分别显示，不能依次追锁而取消原有躲避路线。

先检查整组不同的合法落点、最小安全距离及主母完整占位，再一次生成全部 4、6 或 4 只。临墙时在各自象限或侧面内寻找替代格，保持数量和相对布局。无完整布局时本次不生成，保留待召组，每个正世界回合至多重试一次；成功前不推进轮转或起算共享冷却。控制解除后也只尝试当前一组，不补出积压编队。Mage 在结算前被击杀时，按现有施法者检查取消该次坠牢，正常完成才无掉落退场。

Boss 固定编队不计入普通地图人口上限，包含开场八只 Spinner、每轮 4/6/4 支援及转场十二只 Spinner；存读档保留其编队归属。这个豁免只属于直接编排的成员。普通 Nest 的自然增援、死亡爆怪与后代继续按各自原有生成规则和人口上限处理，不继承编队豁免。一次攻击后退场只适用于 Boss 直接召唤的 Jumper，普通 Jumper 保留原有结束规则。地图拥挤由落点检查处理，不能突破地形或把敌人叠在同一格。

### 固定机制与二阶段进攻

一阶段入场立即开始进攻，各招保留完整预告，展示召唤顺序与围场压迫。正常移动、攻击、恢复和解缚都需要消耗世界时间，停在已锁定的落点会接连被蛛丝命中。支援幼蛛可受正常攻击和控制，成功处理支援应削弱这一轮机制。

正式二阶段同时强化本体技能轴与瞬发召唤轴。候选调整为缩短召唤组间冷却、增加反向横扫与内外二连、提高追踪落丝波次，以及让本体攻击与支援预告更紧密地重叠。主母不必等待支援退场或召唤冷却结束才释放其他技能。四只、六只、四只的召唤数量不自动增长。两条时间表与单招预告需一起校准，保留能够完成整段机制的路线。

### 本体拘束技能

五种常规本体攻击暂名「牵丝缠缚」「扇网缚身」「环丝收缚」「连缀缠丝」「织弹连珠」，全部以拘束玩家为目的。「织弹连珠」生成多个法阵，由法阵脱手连续、大量发射 Mage 的蛛丝球，补充远程进攻。另设「魔织结茧」作为魔织丝茧的完整捕获技能；「织纹共鸣」只维持密度。真实命中应推进蛛丝缠缚，具体每次施加量、修补效果与附带伤害待定。预告让玩家通过离开近身危险区、绕到侧面、切换内外位置或离开旧落点避免缠缚。

| 技能     | 一阶段用法                                                                             | 二阶段变化                                         | 处理方式                                                           |
| -------- | -------------------------------------------------------------------------------------- | -------------------------------------------------- | ------------------------------------------------------------------ |
| 牵丝缠缚 | 近身普通攻击，短起手后牵丝缠住邻近目标，命中推进常规蛛丝拘束                           | 攻击间隔缩短，命中后可衔接另一项有预告的本体技能   | 离开近身攻击格，或利用收招输出；不附加保证后续必中或无法行动的控制 |
| 扇网缚身 | 锁定朝向，显示扇形危险区，随后展开蛛网，缠缚真实命中的玩家                             | 第一扇结束后预告并释放反向第二扇                   | 提前绕到侧后方；第二扇独立显示，不能在结算前突然转向               |
| 环丝收缚 | 以主母为中心，预告内圆或外环其中一处，结算时收拢蛛丝缠缚区内玩家                       | 内圆后接外环，或外环后接内圆，顺序在首段读条时显示 | 根据危险区进入内侧或退到外侧，二阶段连续换位                       |
| 连缀缠丝 | 多波蛛丝依次锁定玩家当时所在格，延迟落下并缠缚命中者；候选三波                         | 候选五波，后几波与支援预告更紧密衔接               | 持续离开已经锁定的落点，把攻击诱导到一侧；落点锁定后不追随玩家移动 |
| 织弹连珠 | 生成两个固定法阵，法阵脱手连射 Mage 蛛丝球；每次发射瞄准玩家当时位置，飞行沿用正常逻辑 | 法阵数量增至五个                                   | 法阵围绕施放时的主母展开，生成后位置固定，完成本轮射击后自然消失   |
| 织纹共鸣 | 定期瞬发，只刷新蛛丝密度衰减计时                                                       | 继续维持，具体周期与阶段时间表一起确定             | 不额外增加密度或造成伤害，见第 5 节                                |
| 魔织结茧 | 强力预告后发射追踪蜘蛛符文；命中连线并进入 Spinner 式对抗，逐步拉近后终击结茧          | 沿用符文、捕获对抗、牵引与终击的完整过程           | 通过对抗脱离；身前终击命中才开始魔织丝茧的缠绕，详见第 6 节        |

牵丝缠缚是普通攻击，其余主要攻击在本体轴上按预告、结算和收招依次安排。「魔织结茧」是包含追踪符文、牵引和终击的技能名，「魔织丝茧」是终击命中后施加的拘束及其成长机制，两者区分使用。瞬发召唤可在这些过程内触发，不能替换或推迟本体招式。每次真实命中的密度增加沿用统一来源结算，同一次命中推进多个装备也只计一次；群体攻击未命中时不增加密度。

织弹连珠参考绳子女巫与史莱姆女巫的法阵发射体验：主母一阶段每次生成两个法阵，二阶段每次生成五个，法阵再独立连射 Mage 蛛丝球 `SpiderlingsMageBolt`，复用其弹体表现与基本命中效果。法阵围绕施放时的主母展开，生成后位置固定，不随主母或玩家移动；每次发射时瞄准玩家当时的位置，飞出的丝球沿用普通逻辑。法阵完成本轮有限连射后自然消失。生成法阵属于主母的技能动作，法阵成形后不需要主母持续引导，可以在主母进行捕获对抗时继续发射。具体布置距离、连发数量、射击间隔与持续回合待定。瞬发召唤轴继续按既定规则独立运行。

追踪符文命中后、魔织丝茧施加前的捕获对抗期间，主母暂停牵丝缠缚、扇网缚身、环丝收缚和连缀缠丝，继续执行拉近与身前终击。织弹连珠仍可生成法阵，已生成法阵也可独立连射；瞬发召唤与织纹共鸣按原有规则执行。结茧后的限时脱困另按第 6 节处理。

环丝收缚的半径必须按当前有效围场与主母所在位置校准。不能让安全内圈或安全外圈落在实体网外，或位于玩家预告期间无法到达的位置。二阶段的两段之间要留出实际换位时间，具体范围与回合数需同时检查正常和轻度减速状态。

连缀缠丝可留下短暂减速丝迹，以增强连续停留的风险；丝迹持续时间有上限，不新增永久实体墙，也不替代八只 Spinner 的施工。每波分别预告、锁定、结算；锁定顺序与剩余波次要可见。停留在旧落点会接连受击，但站到正确位置完成耗时攻击或恢复，不应无条件挨打。

### 本体与召唤的候选组合

| 组合                | 机制顺序与要求                                                                                                               |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 扇网缚身 + 四角喷网 | 本体读扇形时瞬发召来 WebCaster。扇形压迫一侧，四角喷网随后到达，玩家选择侧后路线；需验证扇外路线不被四道喷网全部封死         |
| 环丝收缚 + 双侧跃袭 | 六只 Jumper 按正常逻辑进攻，与本体内圆或外环的结算配合；候选是在跃袭预告后结算内圆，二阶段再接外环，要求连续换位             |
| 连缀缠丝 + 四隅坠牢 | 前几波落丝引导玩家向一侧移动，四个偏移法阵随后锁定；玩家转向离开共同覆盖区，后续落丝留到法阵结算后接上，避免同时封死唯一逃路 |

一阶段从入场起立即开始本体与召唤轮转，并在固定节点使用组合，不设置先单独教学再启用召唤的开场。二阶段以反向第二扇、内外二连和增加落丝波次构成连续机制，减少两组之间的空隙。每个完整组合结束后保留输出、恢复或解缚窗口。

这些组合是编排候选，不能只按两个独立冷却自动相撞。共享召唤冷却不会阻塞本体释放，但整场的固定时间表仍需检查二者重叠后的可行路线。普通移动次数、持续伤害、预告长度与剩余围场共同决定实际难度，不用直接堆高伤害替代机制设计。

两条时间表各自记录下一项与剩余世界时间。本体仍在读条或收招时，只延后该轴的下一项；不挤压既有预告，也不延后已经到时的召唤。完成一轮组合后，至少提供一次能完成有效输出、恢复或解缚动作的窗口。生成后独立工作的法阵仍按自己的时间结算。两条轴的固定顺序和首轮试验时间表见第 7 节。

## 4. 一阶段归零与四巢再生转场

一阶段生命降至零，立即进入转场。这里拦截普通死亡处理，主母不移除、不掉落、不解锁出口，也不直接进入可攻击的二阶段。

转场期间：

1. 二阶段主母从零生命开始恢复，进入转场时立即结算第一次正常回血，之后每个世界回合恢复一次。
2. 主母全程无敌，免疫一切攻击，不移动、不攻击、不施法，也不召唤普通支援。
3. 场地四角附近各生成一个 Nest，共四个。
4. 每个 Nest 附近生成三只 Spinner，主动向玩家进攻，共十二只。
5. 玩家必须摧毁全部四个 Nest，转场才结束。

回血是转场状态的被动效果，不占主动施法。每次恢复二阶段最大生命的固定比例，比例在转场期间保持不变，不随存活巢穴数量减少；具体比例待调试。主母不进行织纹共鸣，因此转场本身不会刷新密度衰减；守巢 Spinner 的真实命中仍按规则刷新。

Boss 房这四个 Nest 沿用普通 Nest 的全部行为，包括既有增援、死亡爆怪和后代行为，不为 Boss 转场额外适配。十二只 Spinner 是额外的初始守军，不是转场总敌人数上限。阶段目标只计转场开始时生成的这四个原始 Nest，普通行为后续产生的其他 Nest 不加入目标计数。

房间生成时预留四个巢位及各自可攻击邻格，施工不得占掉这些巢位；生成器在入场前验证四角完整布局。转场初始化一次登记四个目标的稳定标识和十二个守军位置。受临时占用影响时，先在同角预留区寻找合法替代格；每角的一个 Nest 与三只守军整组落地，未能生成的角保留待生成状态，每个正世界回合至多重试一次，并显示尚待出现的目标数。玩家清走占位单位后即可继续生成；原型须覆盖占满再清空的恢复过程。已创建或被摧毁的编队不再重生，只有四个原始目标全部真实创建并被摧毁才结束转场。存读档恢复目标、待生成状态及死亡记录，不按现存 Nest 总数重建计数。

### 转场结束

第四个原始 Nest 被摧毁后，主母立即停止恢复生命，解除无敌，恢复正常可攻击状态，进入正式二阶段，不要求清完守军或其他增援。摧毁巢穴和结束转场均不额外移除其余敌人。主母保留当时已恢复的生命，不额外免费回满。清巢速度因此影响二阶段起始血量。

回复上限为二阶段最大生命。即使提前回满，也必须等四巢全部被摧毁才能解除无敌。转场开始即进行第一次正常回血，因此极快清巢时也保留这次实际恢复的生命；不另加最低开战血量。每回合恢复比例与二阶段最大生命仍待定。

已有蛛网、在途喷网、已经成形的法阵、旧召唤与存活的开场 Spinner 均继续按原有规则存在、行动、结算或到期退场，转场不统一清场。主母尚未释放的本体攻击取消，不能在无敌期间补放；她的两条技能轴停止推进。进入二阶段保留残留场面，以完整的新预告开始该阶段时间表，不补发一阶段或转场积压的攻击。未完成的主母捕获另按下表处理。

正式二阶段生命再次降至零，才算最终胜利。停止本场攻击、法阵发射、巢穴增援和在途效果，清除本场战斗威胁，解除连线和临时行动锁，取消所有尚未实际进入监牢的收监请求、护送及脱困计时，结算一次奖励并开放正常出口。已穿戴拘束不自动消失。奖励内容待定。

## 5. 织纹共鸣与蛛丝密度

主母在有效战斗阶段定期释放大范围瞬发「织纹共鸣」，只刷新密度衰减计时，不增加密度、不造成伤害、不新增或修补拘束。它不调用会增加密度的普通接触入口，也不恢复已经衰减的数值。

三种支援召唤仅在组内共享冷却。织纹共鸣沿独立的本体技能安排执行，可与瞬发召唤同时发生，不占用或延后召唤组的冷却；其他本体招式同样不受召唤阻塞。转场期间主母不进行任何行动，本体技能轴与瞬发召唤轴均暂停，因此共鸣也暂停；最终胜利、战败押送或离开本房间停止维持。

test.3 已交付的全局密度没有上限，普通有效命中增加 10，带来源残留增加 2，脱困新增进度除以 `1 + D/100`。穿着 Spiderlings 拘束不再阻止衰减；自己的挣扎与换装也不刷新计时。这是现有基础规则，Boss 无需再次实现一套。

现有规则保留十个安静世界回合，超过保留期的安静时间为 `t`，剩余比例为 `2^(-(t/12)^2)`，密度低于 0.5 时归零。共鸣是待实现的额外维持来源，由 `SilkDensity` 提供只刷新安静计时的操作；Boss 不直接写它的存档字段，也不借普通 `contact` 增加密度。主母本体及法阵的真实命中必须注册合法来源，一次命中只提交一次密度变化。需要回归普通拘束、腿袋、普通茧与监牢，避免新增来源改变既有规则。

## 6. 魔织丝茧与战败循环

中文名称为「魔织丝茧」，英文为 Spellwoven Cocoon，具有反抗后继续缠织、增厚与鼓起的成长表现。它通过主母「魔织结茧」技能的身前终击触发，不要求玩家已经穿着普通茧，也不设高密度施放门槛，按战斗轮转出现。密度对已入茧后的脱困收益与回拢效果继续生效。禁用头罩等偏好继续生效。

### 魔织结茧：追踪符文、捕获对抗与身前终击

1. 主母显示明显强于常规招式的技能预告。展开的蜘蛛符文、聚拢的丝线与蓄力变化需要让玩家一眼辨认出这是捕获技能；具体美术与预告时长待定。
2. 预告结束后，主母发射一个可被攻击并消灭的追踪蜘蛛符文。符文在未被击毁、也未命中玩家前持续追踪，不会因等待或持续绕行而自行超时消失；玩家需要攻击将其消灭才能解除本次追踪威胁。符文的基础移动耗时为每格 1.5 个世界回合，保留原生追踪与地形交互。
3. 符文真实命中玩家后，在玩家与主母之间建立 Spinner 风格的可见 tether，并进入类似 Spinner 捕获的对抗。此次命中建立连接，不直接施加魔织丝茧。
4. 对抗沿用 Spinner 的双进度界面与操作，显示「拘束进度：{value}/100」和「挣脱进度：{value}/{goal}」，按钮为「挣开蛛丝 · 精力 10 · 1 回合」。主母推进拘束进度并逐步将玩家拉到身前，玩家消耗精力与世界回合推进挣脱进度。挣脱达到目标则断开连接；同回合完成时先结算挣脱成功。若未挣脱且拘束达到终点，立即对玩家施加 stun，结束本次对抗，玩家在 stun 期间不能行动或继续点击挣开蛛丝。主母的推进速度、挣脱目标与实际拉近步幅待调试。
5. stun 固定持续五个世界回合，期间玩家不能行动。主母在这五回合内执行身前终击，终击真实命中后完成魔织丝茧的初始动态缠绕。终击预告用于展示捕获过程，此时不再提供额外挣脱或走位机会。五回合结束、玩家恢复操作后，开始魔织丝茧的限时脱困倒计时。
6. 结茧后的成长、限时脱困、超时押送与监牢恢复沿用下述流程。

此处复用 Spinner 的连线表现与捕获对抗形式，并加入实际向主母身前逐步拉近的过程。主母是连接的唯一来源；不因此继承普通 Spinner 围场捕获的两来源、闭合围场或腿袋前置条件。对抗期间允许法阵丝球连射，其他四种常规本体拘束招式暂停，详见第 3 节。

### 控制归属与终击条件

每名玩家同时只有一条主母捕获流程。已有追踪符文、主母对抗、五回合缠绕或限时脱困时，不再发射新的捕获符文；该槽位跳过，其他允许的招式继续。普通 Spinner 的对抗、包裹或押送已占用控制时，主母不发起新对抗；在途符文此时命中只消耗符文，不覆盖既有进度。主母控制期间，普通 Spinner 不新开对抗、包裹或恢复牵引；已有装备和普通场地保留。主母流程结束后恢复普通捕获资格，不附送全局免疫。

符文按可通行格寻路，不能穿墙或实体蛛网，也不占普通幼蛛人口。阻路时等待合法通路，玩家仍可攻击；等待不使其自行消失。符文被击毁、首次命中或所属捕获因阶段变化取消时结束，不留下第二次命中机会。

牵引逐格检查地形、占用与主母完整占位，每世界回合最多移动一个合法步幅。主母在对抗中固定站位，朝向可变化。堵路时牵引和拘束推进暂停，玩家仍可付费挣开；不瞬移、不借原生牵引重复移动。进入 100 前必须到达可执行终击的占位外邻格，否则保留至多 99 的进度。拘束满后的第一个世界回合执行真实终击并添加初始魔织层，余下回合完成缠绕；整个行动锁总长仍为五回合。终击失去合法位置或原生装备兼容检查拒绝施加时，结束这次捕获并解除临时锁，不凭动画启动脱困倒计时。

### 动态缠绕与编号叠层

初次施加采用 Spinner 动态腿套的表现：逐步缠绕、已施加部分保留，活动丝尾随缠绕端点移动。初始魔织部分只有少量覆盖，不直接展示最终厚茧；若已有普通茧，新丝层叠在其上，不让原有装备消失。魔织丝茧是独立的外层拘束，使用原生兼容链接保留普通茧、锁与已得进度。移除魔织外层只移除这一件；里面仍有普通茧时，玩家仍需继续脱困，Boss 的本次限时计时则已结束。

初始魔织部分记为第 1 层，之后只用「第 2 层、第 3 层……」表示层数，不使用形态名称。层数采用比五档更细、更长的成长过程；在最终层数上限前，每次有效 Struggle、Remove 或合法 Cut 未能脱困，就在已保留的丝层上新增一层，同时逐步缠织、增厚与鼓起。每次只增加一层，不一次跨越多个编号，也不将多次尝试合并成少数几个形态变化。

魔织层数与蛛丝密度分别记录，层数保留固定最终形态与上限，具体上限待定，密度无上限。成长随同一件魔织丝茧持续，押送与入牢不重置层数，监牢中的有效脱困尝试也沿用每次新增一层的规则。无效输入、缺工具、体力不足不推进成长；本次成功脱困则不再新增一层。

每一层都应出现一次能辨认的新丝缠绕，保留此前已织部分，并显示新增丝线的运动端点。增厚与鼓起随层数小幅累积，不能只更新数字，也不能几次尝试就跳到最终厚茧。高密度时，反抗后的缝隙迅速闭合，茧体鼓起并重新收紧。密度下降后，回拢变慢，裂口或松脱边缘持续保留，让玩家看见脱困开始奏效。最终形态可以保持厚茧外观，不需要自动退回第 1 层。

### 脱困进度

记密度为 `D`、魔织层数为 `S`，本次基础脱困收益为 `G0`。`G0` 是原生下限、工具及状态规则处理后、密度适配前的有效新增进度。现有延迟动作入口已经做密度缩放，魔织茧只能沿用一次，不能对缩放后的收益再除一次：

```text
正常收益 G = G0 / (1 + D / 100)
额外扣减 L = f(D) × c(S)
最终进度 P' = max(0, P + G - L)
```

`f(D)` 随密度增加且 `f(0) = 0`；`c(S)` 随魔织层数提高且有上限。先合并收益与扣减，再判定成功；成功不再成长，未脱困才新增一层，新层数从下次动作生效。

保留原生工具要求、耗时、体力及各方法的进度通道。同一动作的内部延迟回调不能重复扣减或新增丝层。进度不低于零，不积累负数债务。高密度时扣减可抵消全部收益；长期无受击后密度趋零，所有层数均应恢复正的合法脱困收益。

一次有效动作开始时保存其物品、方法、层数和密度，汇总这次动作的原生收益后扣减一次，再进行成功判断。中途失去目标物品或动作未合法提交时不成长。到达层数上限后不再增长，但仍使用上限层数的扣减系数。首轮候选为 `f(D) = k × D/(100+D)`、`c(S) = 1 + (S-1)/(Smax-1)`，并把 `S` 限定在 `1..Smax`；`k` 与进度同单位，层数系数从 1 增至 2。试验先取 `k = 0.25 × Gref`，其中 `Gref` 是固定测试构筑零密度的一次原生有效收益，作为整轮试验的常量。该候选在零密度时扣减为零，高密度时允许净收益为零；仍需用真实原生动作确认各方法、体力消耗与成功时机。

### 超时押送与自然恢复

| 状态       | 规则                                                         |
| ---------- | ------------------------------------------------------------ |
| 缠绕完成   | 玩家获得脱困操作后开始固定世界回合倒计时                     |
| 限时脱困   | 挣扎、等待及其他耗时行动均消耗时间，不因成长重置倒计时       |
| 成功脱茧   | 取消本次收监流程，以新的完整预告恢复战斗                     |
| 到期未脱茧 | 锁定本次抓捕，停止攻击、常规轮转和密度维持，由幼蛛押送至监牢 |
| 入牢       | 保留魔织丝茧、魔织层数、密度与已有脱困进度；结束本次收监计时 |
| 监牢恢复   | 等待密度自然下降，玩家自行挣脱；不由巡逻拆茧，不主动降低密度 |

末回合先结算已提交的脱困，成功优先于超时。魔织丝茧实际施加后，本场主母、开场施工者、支援、守巢者和 Nest 后代停止向玩家提交新的攻击或捕获，不再生成进攻支援或新的连射法阵；施工、存活和普通 Nest 规则保留。已经释放的弹体、法阵余下连射和已锁定攻击继续完成这一轮，不能因停火反复重锁玩家。五回合缠绕自动推进这些旧效果；脱困倒计时仍从恢复操作时开始，数值验收须计入可能剩余的在途命中。主母在有效战斗阶段可以维持密度，转场中仍不共鸣、不执行终击。已施加的茧与四巢回血同时推进，未施加的捕获按第 4 节取消。

正常囚禁阶段要提供足够的无受击时间，避免例行巡逻永久打断衰减。玩家主动再交战后的有效命中照常刷新。存读档保留已提交状态，不重复成长、扣减、生成支援或再次收监。

### 押送与房外返回

超时提交一项由监牢模块管理的魔织丝茧收监请求，载荷包含实际物品身份和房外返回记录。它不要求先穿普通 Cocoon 或伪造普通茧的 anchored 标记。押送者选择、真实移动、失去押送者后的重新分配仍归 `PrisonEscort`，监牢身份、地图持久化和返回归 `Prison`；Boss 只提交一次请求。

押送目的地与四个转场目标 Nest 分开。优先采用可达的现有合法入口；没有入口时，调用现有 Tunneler 付费建巢流程，在地图预留的收监服务区建造。服务区及其可通行邻格不参与围场施工和四巢目标，必须能连接玩家当前位置。四个目标巢全灭不阻止这条流程。没有存活合格执行者时，由房外服务区进场一组专用押送支援，一只 Tunneler 负责建巢、一只 Spinner 负责护送；它们属于固定编队，只有职责空缺时才补充，不按回合反复生成。

等待建巢或押送被中断时，玩家仍能操作和脱困，Boss 不恢复攻击或共鸣，不新增第二个收监倒计时。送达前魔织茧已移除则取消请求，以完整预告恢复当前阶段；转场尚未结束时继续四巢流程。到达合法入口后才提交地图切换，不用隔墙传送替代实际押送。入牢保存当前物品、层数、密度、各通道进度与资源，返回绑定入场前的房外准备点，不能使用 Boss 房内默认来源点。

存档至少保留遭遇阶段、两条时间表、四巢 ID 及死亡记录、固定编队归属、已生成法阵/符文、捕获控制者、物品层数、当前动作提交标识、五回合锁的剩余时间、脱困截止时间、押送请求与房外返回记录。加载只恢复已提交状态；缺失或失效的捕获来源解除临时锁并保留实际物品，不重复执行入场、终击、成长、奖励或收监。

### 首轮时间表

本体先按「扇网缚身 → 环丝收缚 → 连缀缠丝 → 织弹连珠 → 魔织结茧」循环，牵丝缠缚只在未占用的近战行动机会使用，不能挤掉招式预告和已留出的恢复窗口。一阶段连缀先试三波，二阶段先试五波；二阶段扇形改两段、环丝改内外两段。波次、后续段逐一预告，不能与前段同帧结算。

召唤轴独立按「四角喷网 → 双侧跃袭 → 四隅坠牢」循环，一阶段无阻塞时在第 0、12、24、36 回合触发，二阶段在第 0、9、18、27 回合触发。每次以实际成功召唤回合重新起算该轴冷却。共鸣第 0 回合起独立按本体许可每 6 回合尝试一次；只有允许主母行动时执行，禁止施法时不积压。完整原型记录三条实际轨迹，检查第 3 节候选组合是否留有路线，再调整偏移和间隔。

这些时间点是可运行的起点。若与原生 Mage 读条、Jumper 行动或多回合恢复动作冲突，优先延长预告、收招或调整轴间偏移，不缩短支援自身预告，不通过额外免伤规则伪造可躲避性。

### 实施顺序与可判定结果

1. **多格与房间。** 在 KD 5.4.92 和最新官方 5.5 上验证实际占位、路径、单次伤害、中央入场、房外返回点和预留空间。原生龙 `GFX.spriteWidth` / `spriteHeight` 的 144 × 144 绘制参照不证明原生具有多格碰撞。
2. **遭遇与围场。** 打通一阶段、四巢无敌回血、二阶段、胜利与重试，加入八只真实施工者及固定编队人口豁免。覆盖四巢出生占用、后代巢不计数、提前回满、末巢与回血同回合、全部施工者被击杀。
3. **攻击与支援。** 实现两条时间表及独立法阵，核对合法来源、真实命中、完整编队失败重试、被杀施法者取消、正常退场无死亡爆怪。人口设置低于八只和设置为零都要覆盖。
4. **捕获与魔织茧。** 验证符文唯一性、普通 Spinner 控制互斥、牵引堵路、终击兼容拒绝、五回合时长、各层动作和各进度通道。逐一覆盖转场前命中、终击前归零、茧已施加后转场、末回合脱困和最终胜利同时超时。
5. **监牢与完整交付。** 从四巢全灭且没有存活护送者的二阶段败北，实际建巢并押送，保留物品和进度，静候脱困后回房外，再次进场重开。各阶段存读档、七语言文本、正式入口与奖励完成后，用同一个最终 ZIP 通过两版本完整验收。

每项后续实现票都链接 #165 及对应规格段。原型已经进入实现与原生验收，具体通过范围以[兼容记录](COMPATIBILITY.md)为准；设计审查和公式检查不能替代玩法验收。
