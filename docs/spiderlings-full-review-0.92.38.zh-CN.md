# Spiderlings 0.92.38 整体验证与发布记录

审核日期：2026-09-14。正式版从 0.92.37 升至 **0.92.38**；Spinner 独立试玩同步为 **0.92.36-test.9**，正式基线仍是 0.92.36。测试玩法没有混入正式版。正式源码保存在 `fix/spiderlings-0.92.38-review` 分支；主工作区 `Spiderlings_0.91/` 是 test.9 源码。

## 修复

1. **KD 5.5.3 警报接收者遗漏实体目标记录。** 原生 `KinkyDungeonMakeNoiseSignal` 设置接收者的 `gx/gy`，却对发信者调用 `KDUpdateMoveToEntity`。Mod 复用原生返回的实际接收者，同步其追踪坐标和目标 ID。保留原生听觉、阵营、事件改向以及蛛丝禁言；没有该辅助函数的旧游戏沿用原路径。实际 5.5.3 安装包测试确认接收者追踪到发信者。
2. **掘巢请求不存在的弹丸图片。** `SummonNestEntrance` 缺少其他召唤法术已有的 `noSprite`，导致绘制时请求不存在的 `Game/Bullets/SummonNestEntrance.png`。补齐标记，仍由原生逻辑执行原地引导、召唤、提示和音效。三版本真实施法均生成巢穴，且不再登记这个弹丸的视觉对象；test.9 也通过同项验证。
3. **避免重复使模型缓存失效。** 外观颜色不变时，原来的 `afterDress` 回调仍对每件装备清空原生模型缓存。现在只在保存的模型副本确实需要修正颜色时刷新；换色、穿脱和位移贴图就绪后的刷新继续保留。回归验证连续 24 次未改变颜色的回调不再重复清空缓存。
4. 继续包含 **0.92.37 的玩家回退召唤对话崩溃修复**，无需迁移存档。原始报告、调用栈和复现见 [此前诊断](spiderlings-crash-0.92.36.zh-CN.md)。

## 仍需区别对待的异常

- 5.4.92／5.5.0 的快速切图、换装和暂停恢复记录到原生音频 `play()` 被 `pause()` 中断；5.5.3 裸游戏也有原生图片加载 `Event`。早期战斗样本请求过原生 `Game/Items/.png`、`Game/EnemiesBound/Maidforce.png`。最终正式包本次正常绘制的 1,000 回合没有 page error，仅留下原生 `Game/Locks/Red.png` 的 404。全部原始异常留档，不笼统声称所有运行都零日志。
- 菜单状态下大量注入回合的 5.5.3 压力运行多次出现渲染进程退出，包括串行复核；禁用 Mod 模型刷新仍可复现，关闭游戏声音则完成同类 1,000 回合。现象与音频路径相关，但具体根因尚未闭环。正常绘制、每回合让出事件循环并保持声音开启的长回合复核完成；不能把极端压力场景也宣称为已修复。
- 本次结论适用于已列出的主要 Mod 流程和默认设置，不等于通关全部随机种子、任意游戏版本、无限数量配置或全部 Mod 组合。
