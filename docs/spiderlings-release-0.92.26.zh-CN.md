# Spiderlings 0.92.26

幼蛛现在以蛛丝暂时制服敌对 NPC；对玩家的直接伤害也调低了。

- 普通有效命中对玩家造成基础 0.05 tickle，成功绑定同样结算；跃击固定为基础 0.10，取消未推进时的额外伤害。
- 对 NPC，普通近战提供基础 1.5 束缚，跃击和喷网直击为 3，喷网轨迹为 0.5，直接 HP 伤害为零。保留原生抗性、护盾和挣脱；不会自动生成 NPC 实体装备。
- 普通近战与跃击实际增加束缚才消耗幼蛛。轨迹按来源和目标每回合最多成功一次，不同喷网幼蛛可以协作。
- NPC 跃击锁定原目标与预警格，移动可以躲避；死亡、失去敌对关系或读档会清除预警。起手提示区分玩家与 NPC。
- 修正原生 NPC 近战把纯束缚误判为攻击失败，以及阵营友好度阻止幼蛛喷网命中女仆的问题。

这是暂时控制：女仆仍可按原生规则挣脱，女仆长等高阶 NPC 的束缚门槛保持原值。

验证：227 项自动测试通过；KD 5.4.92、5.5 的原生近战、喷网施法、延迟跃击、25 回合混战及存档往返检查通过。
