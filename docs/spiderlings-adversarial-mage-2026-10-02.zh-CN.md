## 实际遭遇与玩家判断

下表为每策略6种子，格式“5.4.92 / 5.5.3”。“有新增束缚”指最终至少一件普通 Webbing，不代表不能逃脱。

| 策略                          | 击杀 Mage | 有新增束缚 | 行动数     | 最终意志范围      |
| ----------------------------- | --------: | ---------: | ---------- | ----------------- |
| 连续等待                      | 0/6 / 0/6 |  5/6 / 5/6 | 均14       | 7.5–10 / 7.75–10  |
| 上下各走两格，反复局部躲避    | 0/6 / 0/6 |  4/6 / 2/6 | 均14       | 8–10 / 8–10       |
| 向东持续撤离                  | 0/6 / 0/6 |  3/6 / 2/6 | 均14       | 9.75–10 / 9.75–10 |
| 原生 StaffChain 追近并近战    | 6/6 / 6/6 |  2/6 / 1/6 | 4–6，中位4 | 9.95–10 / 9.95–10 |
| 正确朝向后先发 Firebolt       | 6/6 / 6/6 |  0/6 / 0/6 | 均1        | 均10              |
| 初始2体力/0法力/4意志向东撤离 | 0/6 / 0/6 |  3/6 / 2/6 | 均14       | 3.75–4 / 3.75–4   |

**好玩之处**：单独 Mage 提供了可辨认的职责差异。连续等待会放任其依次放出控制；直线撤离保留资源但没有拿到击杀收益；近战要付出接近过程和3体力一次攻击；法师可用原生元素攻击先杀3HP施法者。控制的威胁主要来自敌人有时间布置，并非所有构筑必须用同一招解控。

**具体遭遇**：5.5.3、`mage-encounter-5`，等待14行动最终6件束缚、意志7.75；同种子持续撤退只留下1件、意志9.75；StaffChain 接近6行动击杀，1件束缚、意志9.95；首发 Firebolt 一行动击杀且没有束缚。Firebolt 基础法力消耗3，但本初始状态原生 ManaRegen 抵扣了首发，最终法力仍15；不能写成 Mod 提供免费技能。

**无效策略的原因可学习**：局部上下晃动能让直线丝球落空，却没有真正离开 Collapse 范围。5.5.3、`mage-encounter-4/5` 仍各增加5件束缚、意志降至8；5.4.92亦有4/6同类结果。这是“大范围落点需要离开范围”的代价，不是无法行动。样本不足以比较两个游戏版本的发生概率。

**打断边界**：受控 Collapse 落点 `(12,10)`，第5行动才结算；停在中心减少2意志并尝试5次普通束缚推进；连续向东移动五步完全避开；移除/杀死施法者取消待结算 Collapse。只眩晕施法者5回合不会取消已放置的 Collapse，已发出的丝球也在施法者死亡后正常命中。玩家应区别“停止后续施法”与“消除已经布置的威胁”。这轮没有证据支持把既成法术全部因眩晕而取消。

## 丝球、符文与茧资格

- 原生碰撞探针：玩家直线命中减少0.25体力/0.25意志，推进一次普通 Webbing；移到相邻行或在中间 `(10,10)` 放墙均无伤害与束缚；原生玩家护盾5完全挡住时无额外 Webbing。两版一致。
- `glueDamageResist` power1 将接触损失减为0.125/0.125，但仍有一次束缚推进；power1000仅留下约0.00024975的正伤害，亦推进一次。这最后一个探针内部名 `spell-immune` **不是真免疫**，报告将其视为极高抗性。它显示束缚推进按有效接触而非伤害线性缩放；目前描述没有承诺抗性会按比例减少层数。本轮保留此方向，若要改变需另比较抗性构筑的控制定位。
- 符文已有原生回归核对：从 placing 到 armed，踏入中心后3×3爆发；预警为 `2 + ceil(native Slow/2)`，零时间更新不推进、连续等待不续期。普通与完整腿袋分别覆盖；具体最终运行记录由最终 `mage-timing` 原生验收提供。这不能代替所有狭窄地形的实际退出成功率。
- NPC资格受控探针，Tome/Staff/Mage三来源各测轻度与完整绑定：原生绑定2时均仍可行动、无茧；绑定50且原生 `KDHelpless` 为真时才形成相应来源的茧。Tome附带4件临时束缚，Staff不附带这套物品；不是无条件命中就出茧。用原生 `KDTieUpEnemy` 移除 Slime 后下一回合三来源都清除茧资格及外观。这是恢复同步验证，未把人工解除算成自然挣扎速度。
- 当前蜘蛛图标按明确要求保留为占位。本轮不把 test79 历史透明丝球说明标成当前问题，也没有制作或调用 AI 素材。

## 武器与同阶段原生参照

参照：SpiderlingTome/SpiderlingStaff均 rarity4；StaffGlue/StaffChain亦为原生 rarity4，BondageTome为原生 rarity3，因此后者是获取略早的参照而非完全等价。此处不只比较面板伤害，直接比较达到“死亡或原生完全束缚”的行动与实际资源支付。

受控数值模拟，普通10/15/10面板、玩家 `(8,10)`、相邻目标 `(9,10)`、楼层12。每格为 **攻击数中位 / 支付体力中位 / 等待回复数中位**；结果在两版均相同，例外是 BondageTome 对 Wolfgirl 到预算上限仍大部分未完成。所有完成组攻击次数最小=最大，因此样本内中位及较差攻击数相同。32种子中的原生束缚残量仍有变化。

| 武器            | Maidforce HP8 | BanditGuard HP11 | Mummy HP8   | Wolfgirl HP20           |
| --------------- | ------------- | ---------------- | ----------- | ----------------------- |
| SpiderlingTome  | 2 / 3 / 0     | 2 / 3 / 0        | 4 / 6 / 0   | 10 / 15 / 11            |
| BondageTome     | 3 / 4.5 / 0   | 4 / 6 / 0        | 5 / 7.5 / 0 | ≥24 / 36 / 54，预算截断 |
| SpiderlingStaff | 2 / 6 / 0     | 2 / 6 / 0        | 3 / 9 / 0   | 5 / 15 / 11             |

所有非截断组均32/32达到原生完全束缚、没有直接击杀。BondageTome/Wolfgirl在5.4.92仅2/32，5.5.3为0/32在24攻击预算内达成，因此不能将24写成其预计完成次数。实际体力支付在攻击后、推进时间前采样，回复与资源净变化另记，避免把回复抵消当成低消耗。

防御差异由原生保留。以5.5.3 Maidforce为例，Tome两击实际造成3.075HP损失、最终约11.47绑定；原生BondageTome三击损失4.5HP、约9.71绑定。蜘蛛杖两击损失6.15HP，原生胶杖6.765HP；对 Wolfgirl 胶杖4击就完成、蜘蛛杖5击，但胶杖多花1体力并多等待2行动。**蜘蛛武器偏向控制与效率；原生胶杖在该目标有更强伤害，不能因为蜘蛛杖7绑定面板而断言全面替代原生武器。** 此矩阵暂停反击，等待11/35/54行动在真实遭遇中显然有被攻击风险，不能把它当成安全打法。

## 主动技能：走位、效果和代价

真实移动目标对照使用普通面板、SpiderlingStaff装备、无Tome副手、玩家 `(8,10)`、目标 `(12,10)`、相同16种子 `native-spell-{NPC}-{0..15}`，一次原生施法加3次等待。保留NPC原生追击与走位，并禁用初始 ManaRegen 抵扣以核对费用；仍保留每回合0.3法力回复。下表每个单元格依次列出“命中数（5.4.92/5.5.3）；完全束缚数（5.4.92/5.5.3）”，两版各16样本。

| 技能           | 原生基础法力 | Maidforce命中 / 完全束缚 | Wolfgirl命中 / 完全束缚 | 实际命中结果                                             |
| -------------- | -----------: | ------------------------ | ----------------------- | -------------------------------------------------------- |
| Silken Snare   |            2 | 8/9；8/9                 | 7/8；0/0                | Maid剩4.85HP、绑定10；Wolf剩15.275HP、最终绑定约9.13     |
| 原生 ChainBolt |            2 | 16/16；0/0               | 16/16；0/0              | Maid剩5.5HP、最终绑定约2.12；Wolf剩18.4375HP、约1.54绑定 |
| 原生 SlimeBall |            4 | 13/13；0/0               | 13/12；0/0              | 地面与持续球产生多次命中，Maid剩3.8–8HP、Wolf剩6.65–20HP |

Snare是强力单目标控制，命中轻型人形目标能直接达到完全束缚；对20HP Wolfgirl未能一发解决。原生 ChainBolt在此移动局面更稳定，射程50且有链式地面/控制联动；SlimeBall有持续球与地面输出，代价4法力及 Arms 组件。Snare射程6、首目标停止、不穿墙、冷却3，但不需要组件。目标斜向走位造成Snare未命中；checkout 的 `.scratch/adversarial-mage/snare-trace/{baseline,github}/results.json` 中逐帧位置与原生碰撞日志没有显示穿过目标丢失命中的缺陷。表中的命中率只能描述这批特定距离与走位，不能推断总体命中率或直接比较所有弹道速度。

四行动后法力净损失分别0.8/0.8/2.8，是2/2/4支付被1.2原生回复部分抵消，**不是实际费用0.8/2.8**。资源不足、超出距离、冷却中输入均失败，不花原生行动或法力。Snare朝墙发射会支付并撞墙；Convergence无直视线落点直接拒绝。本探针墙案例在拒绝之后另手动等待三次，因此其最终clock3不是失败输入付费。

Convergence移动目标：每版12种子 `convergence-moving-0..11`，分别瞄准Maid当前格 `(12,10)` 或提前瞄准其接近路线 `(10,10)`，一次施法加3行动，目标保留原生移动。两种瞄准均12/12造成完全束缚与茧；但提前瞄准明显增加中心/内圈伤害与绑定，而不是提高本样本的解决率。5.5.3当前格瞄准10/12只中外圈2伤害/9.6实际绑定，提前瞄准7/12中内圈4/19.2、3/12中中心6/28.8、2/12停住而仅中外圈。法术基础4法力、冷却8、射程6、施法后再过2行动结算；21格区域按视线阻挡过滤，不伤玩家与友方。可预测走位是一项有收益的技能，广范围也使轻型Maid容易被控制；它对重型、免疫、狭窄遮挡地图的普适胜率仍未测定。
