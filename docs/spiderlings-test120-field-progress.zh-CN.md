# 场地施工人手、借调重评与最终职责

版本 `0.92.36-test.120`，对应 [Issue #124](https://github.com/duromumuyazu74-rgb/Spiderlings/issues/124)。

## 行为变化

总控保留大场地优先选址，并按未完成锚点、丝线连接和损伤估算工程人手：每十二项待处理工作配置一名施工者，普通工程最多四名；通道仍保留其关口需求。供给判断保留这部分人手，避免尚未建好的大场地只剩一名工人，而其他成员不断开新场地。有真实剩余人手和独立需求时仍允许并行施工。该比例是调度规则，不能替代实际施工积分或保证固定完工回合数。

较高优先级的捕获、回收或维修需求可以借用普通施工者，但供给场地仍保留最低一名施工者，受威胁场地保留两名，实际来源继续保护。独立新建不能借此绕过工程人手保留；供给场地自身有同等或更紧急需求时，也不能按普通施工的优先级放人。

已有工程只有具备合法待执行工作和可达施工者，才作为可恢复覆盖；已经准备完成的场地继续作为可用覆盖。全员受捕获来源保护、无法工作或不可达时，受损工程保留身份和已付投入，等待补员，不把等待范围当成可靠覆盖阻止其他选址。

总控持续重评借调。接收需求减少时返还多余且未受保护的成员；原场地有更紧急的真实缺口时，在保留接收场地最低人手后召回；在途连续八次正时间移动尝试受阻且存在合法返回路线时，先返还再等待重试。有合法下一步且正在积攒原生移动积分的等待不算受阻。派遣和返还仍由总控独占移动职责，保持原物理归属；实际 Capture、Recovery、NPC 来源及必要防御成员继续受保护。新借调和真实到达清除上一段旅程的阻塞计数。

没有实际来源职责的诱导成员也能接受待执行维修，包括走到施工位置的付费移动，避免唯一成员被计为可用却一直不维修。维修结束后重新参与诱导；实际来源与必要防御保护保持不变。

Spinner 的移动、攻击和施法共用 Duties 的一次最终裁决。AI 提供感知与工程事实并执行原生付费动作，维护让步只提出建议，由 Duties 在真实行动入口复核来源保护、工程身份和待执行工作后释放。取消或改派后失效的职责本次等待，后续阶段不能自行恢复原生攻击或移动。零时间和加载不执行上述行动。

## 验证范围

新增生产接口回归覆盖：四名施工者优先保留一个大工程、八名施工者合法并行、没有可用工人的受损覆盖、需求缩减、原场地告急、受阻返还和重新借调、维护释放前新增 Recovery 保护，唯一诱导成员在远处时的付费维修，以及取消后的原生阶段封锁。已有付费施工、捕获、回收、通道、保存加载和零时间回归保留。

原生场地指挥场景增加四人与八人调度检查，要求规划不产生施工记录，随后正常原生行动推进原工程；另以原生绑定减速核对九次积分积攒不会误触发受阻返还。最终同一安装包的双版本结果和完整交付检查见[兼容性记录](COMPATIBILITY.md)。受控场景不等于完整楼层平衡试玩。
