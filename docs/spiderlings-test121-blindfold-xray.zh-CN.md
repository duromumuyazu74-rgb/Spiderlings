# 丝织眼罩的原生面部透视

版本 `0.92.36-test.121`，对应 [Issue #126](https://github.com/duromumuyazu74-rgb/Spiderlings/issues/126)。

原生视觉透视分为身体和面部两档，第二档才透视眼罩。普通眼罩与厚眼罩现在保持原生 `Blindfold` 模型层身份，让换装逻辑正确识别面部遮挡。普通显示和身体透视通过原生 `SwapLayerPose` 绘制到 `Brows`，保留前发、眉毛覆盖；面部透视优先切回 `Blindfold`，使用原生 `XrayFace` 遮罩。关闭透视恢复原有覆盖。

两种颜色共用该规则。拘束、致盲数值和叠层关系保持原样；厚眼罩覆盖下的普通眼罩不会在透视时重新显露。没有修改原生层组、全局透视流程或原画。

回归执行原生图层选择函数；原生场景对照普通 ClothBlindfold，并检查两种颜色、普通与厚眼罩、普通眼罩被厚眼罩覆盖、0/1/2/0 切换、实际面部滤镜和致盲数值。最终同一 ZIP 的双版本验收与完整交付检查见[兼容性记录](COMPATIBILITY.md)。
