## 进入与操作

1. 新建角色，在 Perk「起始场景」选择 **结网幼蛛试玩 / Spinner field trial**。进入 31×21 平坦地图，初始位于试验区域西侧外部（3,10）；两只尚未发现玩家的 Spinner 开始布场，一只 Jumper 暂时等候。携带剪刀、两瓶精力药水和备用腿袋。不要同时选择「丝茧初醒」。
2. 原地等待，观察 **先放地面陷阱，再在已放好的两个陷阱之间拉丝**。四处陷阱构成 7×7 区域的角点；每条连接都可阻挡通行。Spinner 按真实行动预算工作，移动方向影响下一条优先封锁的退路。初始等待约九回合完成四陷阱、三条连接，西侧保留入口。不进入时会继续加固连接；布场耗时随行动位置和占格变化。
3. 从西侧入口进入；可向右六格，再右下一格到（10,11）后等待，避开入口内侧的 Spinner。继续向敌人走会变成攻击，可主动击败它们阻止捕获。进入后 Spinner 封住最后一边并接近。未连接处可通行；踩到地面陷阱会短暂减速。**四条连接完整、玩家仍在内部、至少两只可行动敌对 Spinner 位于场内近战范围**，才满足捕获条件。无需踩中某个开关来开启对抗。
4. 对抗一开始就**双腿并拢**，显示半透明粗蛛丝宽带逐圈缠绕。上身和手臂保持原有状态；此时没有真实腿袋或普通腿网。白色拘束条与绿色挣脱条独立增长。
5. 点击「挣开蛛丝」消耗界面精力 10，增加 25 挣脱量并推进一世界回合。两只时目标 75，连续三次可成功；拘束条每回合 +12.5，等待八回合会填满。双方同回合完成时玩家成功，参与者眩晕四个后续世界回合，预览、强制姿势与围网解除。
6. 对抗前或中途点击「加入一只 Spinner」。抵达参与距离才计数；加入提高蜘蛛效率和挣脱目标，已有进度保留。三只每回合 +16.5、挣脱目标 100；四只 +20.5、目标 125。更多蜘蛛进一步缩短时间并提高工作量。可以攻击、失能或破网反制；减员后仍有两只则继续，不足则中断。
7. 拘束条先满则失败，随后**五个自动世界回合**实际施加同一腿袋，依次 20%、40%、60%、80%、100%。菜单暂停自动推进。完成恢复操作并撤网，其他蜘蛛恢复攻击并重新预警；腿袋单独装备时约两回合走一格，仍能攻击、用物和整体脱困。
8. 对抗与实际包裹期间，其他蜘蛛暂停攻击玩家，在合法空位调整站位等待；已经起跳预警的 Jumper 撤销本次预警，结束后重新起手。非参与 Spinner 可继续接近加入协作。
9. 「重置试玩」重建场地并补给；「放出跳跃幼蛛」提前开放其 AI。增援按钮不耗世界回合，最多八只存活 Spinner，实际包裹期间不可添加。

**Spinner 施网命中后持续存在**，可以正常被击败。普通地图仍使用原生寻敌和普通腿网；陷阱连接布场与协作捕获只在这个 Perk 场地提供。

## 陷阱、连接与反制

地面陷阱用原生 Trap 接点触发，初始可踩过；一次触发给予 `MoveSpeed -1`（持续参数 2，包含踩中当回合），不直接穿戴拘束，触发后仍可用作连接锚点。Spinner 每次预算充足时放一处陷阱或连接一对已有陷阱；完成的连接由原生可攻击障碍组成，不会生成在玩家或敌人占用格上。

连接主体初始 HP 2，金色弱点初始 HP 0.5；Spinner 空闲布场动作每次修补一个结点 **0.1 HP，最高 2**，每条连接显示最薄弱处生命。攻击沿用原生射程、伤害与占格。任一已织结点断裂或锚点被拆除会撤掉本轮临时围网、取消控制。已形成的腿袋保留为可解除半成品。拆除后显示倒计时，第 19 个后续世界回合仍不重建，第 20 回合恢复准备；随后存活 Spinner 按行动预算重新放陷阱。完成或挣脱后同样等待重建，不生成新的 Spinner。提前离开区域不会凭空被拉回；连接闭合后玩家在场外不会触发捕获。

## 默认值与存档

| 项目                 | 数值或行为                                        |
| -------------------- | ------------------------------------------------- |
| 场地                 | 31×21 平坦地图；四陷阱、四连接，围场外径 7×7      |
| 拘束条               | 目标 100；每世界回合 12.5 + 4×额外参与只数        |
| 两／三／四只完成时间 | 8／7／5 世界回合，按实际行动者计算                |
| 挣脱条               | 目标 75 + 25×额外参与只数；每次有效主动挣脱 +25   |
| 主动挣脱费用         | 界面精力 10（内部 1）、一世界回合                 |
| 重建与加固           | 拆除后 20 世界回合；每次 +0.1 HP，上限 2          |
| 失败后实际施加       | 固定五世界回合，每回合 20%                        |
| 腿袋                 | 独立 ItemLegs，hobble 2；双腿并拢，上身与手臂自由 |
| 完整脱困             | Cut 4 次，Remove／Struggle 6 次                   |
| 未完成脱困           | Cut 2 次，Remove／Struggle 3 次                   |
| 颜色                 | 原色／粉色宽带；地图连接线始终 #FFFFFF            |

脱困保留原生工具、可达性、精力与移动债务规则。剪切销毁，移除／挣扎回收；混合方法共享比例进度。外部装备实例、锁与进度保持；腿袋只阻挡被覆盖的自有腿／踝／脚内层操作。

陷阱、连接、HP、重建剩余回合、参与者、双进度和物品完成度随原生存档保存。离图、战败、缺少来源或场地损坏会清理本次控制。test.1–3 的旧围场不具备四陷阱连接结构，加载会解除旧对抗并保留已形成物品；请新建角色选 Perk，或使用场内重置体验完整流程。

## 视觉与限制

宽带采用方案 D 的螺旋路径，使用 Band.png 的纹理网格逐段铺叠；活动宽尾单独使用 Tail.png。最终阶段淡入 Finished.png 与 Closure.png。几何定位沿用 2480×3508 人物坐标，导出的四张局部 PNG 采用各自固定画布，见画师交接页。原始 Cocoon PNG 与 atlas 未改写。对抗和实际包裹在各自世界回合进度之间插值，渲染帧不推进玩法。

四张立绘图是 Image Gen 生成的测试素材，供画师按部件替换与精修。试玩场地使用四角矩形连接，尚无普通随机地图上的任意形状结网。正常腿袋提供两次真实输入的 Jumper 预警机会；额外腿具、地面陷阱或喷网减速可能使玩家来不及离开目标格。默认值未做胜率平衡定稿。
