---
name: research
description: Investigate a requested question using primary sources and save cited findings.
---

Investigate the requested question using sources that own the claim: official documentation, source code, specifications or the named author's original material. Fetch the relevant body rather than treating a search snippet as the source.

Use existing findings before repeating searches. Save a concise cited report in the owning project's documentation or scratch area. Distinguish established facts, inferences and unavailable evidence.

Delegate only when the session permits it and a bounded investigation can run alongside useful independent work. Otherwise investigate directly. Finding a first source is not completion when the request requires a comparison or a complete reading.
